## 四、标准作业程序（**五套，各四栏**）

### SOP-A　出件（**正式件**）
| 栏 | 内容 |
|---|---|
| **输入** | 令条／裁定／实证数据 |
| **动作** | **七步：出件前必读 → 打钟 → 术语闸 → v5 署签 → 投递三处 → 总线 emit → 台账写入** |
| **输出** | **正式件（含署名块）＋ 台账一条** |
| **校验** | **打钟一致性（真实钟）｜术语闸三态（`CLEAN`／`QUALIFIED`／`UNMEASURED`）｜署名复算｜台账 verify** |

### SOP-B　记账（**每轮至少一行**）
| 栏 | 内容 |
|---|---|
| 输入 | 本轮动作与读数 |
| 动作 | **先 `mkled`（须附非空 `seal_files`）→ 后 `ledger_write`** |
| 输出 | **台账新行（含 hash 链）** |
| 校验 | **闸检一致（行数＝快照 `lines`）→ 追加 → 刷快照 → `verify` PASS** |

### SOP-C　推送（**双通道**）
| 栏 | 内容 |
|---|---|
| 输入 | 已提交之正本／镜像 |
| 动作 | **改 → 签（`sha3-tree build`）→ 推 → 核** |
| 输出 | **`origin`（GitHub）／`gitcode` 皆与本地同源** |
| **★校验** | **★`git log origin/main..HEAD` 条数＝0（★非匹配 push 输出之文本）**；**★推前闸须过** |

### SOP-D　对账（**SHA3-512 树**）
| 栏 | 内容 |
|---|---|
| 输入 | 正本仓 ＋ 镜像仓 ＋ 技能仓 |
| 动作 | **`node tools/sha3-tree.mjs verify`／技能仓 `MERKLE.json`** |
| 输出 | **一致性结论** |
| 校验 | **★不等即中止并如实报；★不得"抽验过关即判全通"** |

### SOP-E　异常处置（**本席实证固化**）
| 现象 | 处置 | 禁则 |
|---|---|---|
| **★`404`** | **判"无此路"** | **不得记为"无预算"** |
| **★`429`／`402`** | **判"有路无预算／需付费"** | **不得记为"无此路"** |
| **★`403`（持续）** | **判"权限或通道变更"，记为待裁** | **不得当瞬时限流** |
| **★代理端口不通** | **判网络出口变更；核实为 TCP 通≠HTTPS 可用** | **不得改直连硬推** |
| **★工具缺失（`node`／`kdocs-cli`）** | **停相应腿、如实报、列入待办** | **不得绕过签名闸硬推** |
| **★云盘根变更** | **建 junction 使新旧路径合一（可逆）** | **不得删旧根数据** |
| **★台账缺口** | **重基线＋缺口永久标注** | **★绝不伪造、不冒充完整** |
| **★镜像无关历史** | **先研判，再 `--allow-unrelated-histories` 非破坏合并** | **不得强推** |

## 五、留痕与审计（**全程可追溯**）

1. **台账**：**hash 链（每条 hash ＋ prev 指针）＋ 快照（`lines`／`last_hash`／`size`／`mtime`）**；

4. **历史版本**：**`archive\docs\<key>\v_<YYYYMMDD_HHMM>.md` ＋ `sections_*.json`（节级可微）**；
5. **元数据完整**：**目录结构、修订记录、附件、权限设置随件登记；★历史版本可随时调取**。
