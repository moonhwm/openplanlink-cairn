## 二、★★★★★ 信封规范（**Envelope v1**）

**★ 实测样本（`.a2a-node-dlq.json` 首条）**：
```json
{"version": "a2a-hmac-sha3-512/v1", "key_id": "opl-a2a-2026q4",
 "sender_id": "cairn-dsh", "recipient_id": "unknown-seat",
 "timestamp": "2026-10-03T23:11:41+08:00",
 "nonce": "2a08d1227b069f053ef8311afb684298",
 "body_sha3_512": "7cec894011a8d37d5c16452ca5d2c10a…", "tag": "61e35e7b41a0b4342200bcad…"}
```

| # | 字段 | 类型 | 约束 | **★实测** |
|---|---|---|---|---|
| **1** | **`version`** | string | **`a2a-hmac-sha3-512/v1`**（**协议标识含算法族**） | **✓ 逐字一致** |
| **2** | **`key_id`** | string | **密钥标识（用于轮换与旧签验证）** | **`opl-a2a-2026q4`** |
| **3** | **`sender_id`** | string | **发件席（席位名）** | **`cairn-dsh`** |
| **4** | **`recipient_id`** | string | **收件席；★须∈名册，否则入 DLQ** | **`unknown-seat` ⇒ 被拒（见 §六）** |
| **5** | **`timestamp`** | string | **RFC 3339 **带时区**（`+08:00`）** | **✓** |
| **6** | **`nonce`** | string | **32 位十六进制（128 bit）** | **✓（`.a2a-node-nonces.json` 为 32 hex 数组）** |
| **7** | **`body_sha3_512`** | string | **正文之 SHA3-512（128 hex）⇒ 完整性** | **✓ 128 hex** |
| **8** | **`tag`** | string | **HMAC-SHA3-512 标签（对信封规范化串签名）** | **✓ 64 B 密钥（`.a2a-node-hmac-key.bin`）** |

**★ 封装链（实测）**：**JSON-RPC 2.0 正文** ⇒ **base64（`body_b64`）** ⇒ **信封（8 字段）** ⇒ **`tag`**
**★ 实证**：**`body_b64` 解出 ＝ `{"id":"82ebaf0f-…","jsonrpc":"2.0","method":"seat…"}`** ⇒ **★正文即 JSON-RPC 2.0，方法名以 `seat…` 起首** ✓
