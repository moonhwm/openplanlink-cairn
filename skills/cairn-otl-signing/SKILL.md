# 石敢当Cairn 席 · 署名与唯一标识符技能（cairn-otl-signing）

**一句话**：让"**谁改的**"与"**改的是哪一版**"**可被第三方逐字节复算**——而不是靠自称。

## 一、唯一标识符之定义（本技能之基石）

```
唯一标识符 = (seat_key, 公钥指纹)  ＋  正文 sha256（署名块之前）
```

- **三者任一不同 ⇒ 非同一署名**；
- **复算规则（★必须逐字一致）**：取文件字节中 `\n<!-- SIG-BLOCK` **之前**的部分计 SHA-256；
- **块前仅保留一个换行**（尾随换行归属统一，否则复算必错——本席在此错过五轮）。

**为何要有"正文摘要"**：**公钥只能证"是谁签的"，不能证"签的是哪一版"** ⇒ 二者合用方能抗"事后替换正文、保留旧签名块"。

## 二、三态幂等判据（防"占位块跳过"）

| 态 | 特征 | 处置 |
|---|---|---|
| **占位块** | 有哨兵 `<!-- SIG-BLOCK` 但**无 64-hex 摘要** | **截断重写**（★历史事故：占位块被当作"已签"而跳过） |
| **旧块** | 有摘要但**与现算不符** | **截断重写**（摘要须取**截断后**之正文现算） |
| **有效块** | 有摘要**且复算逐位相符** | **幂等：不动作**（★"存在"≠"正确"，**必须验证相符**） |

## 三、写后自验（本技能之安全底线）

```
追加署名块 → 立即回读文件 → 重算正文 sha256 → 与块内摘要逐位比对 → 打印"逐位相符 ✅/✗"
```

**任何未打印"逐位相符"的署名，一律视为未签**（承"报告值≠核实值"）。

## 四、时点：机器生成，禁止手写

- **用 `scripts/clock_stamp.py`** 生成"时点"行（`--start HH:MM` 声明起时，末时取真实钟）；
- **审计口径**：**以署名块时点为准**（工具取真实钟）；**件正文时点若为手写，须视为不可靠**。
- **★本席真实事故**：曾以"每轮约 40 分钟"之假想手写正文时点 ⇒ **可比对 31 件中 28 件与署名时点相差 ＞5 min，平均 4.89 h**（最大 11.5 h）⇒ **同一件内两时点相冲**。故立此规。

## 五、全语料署名审计（覆盖率口径）

```bash
# 三分：相符 / 不符 / 无签名块
#   "相符"  = 有摘要且复算一致
#   "不符"  = 有块但摘要不符 或 文件不可读（★不可读不得计入相符）
#   "无签名块" = 该件尚未署名（历史件属正常，须与"缺陷"分开计）
```

**★审计纪律**：
1. **失败即中止**（文件锁、编码错误均不得记为"通过"）；
2. **语料级结论须附"总件数／相符／不符／无块"四数**；
3. **历史无签名件不得追改**（只增不改 ⇒ 以加性补注或新版件处置）。

## 六、已知陷阱（皆为真实事故）

| # | 陷阱 | 后果 | 防法 |
|---|---|---|---|
| 1 | **占位块被跳过** | 件实际未签 | 三态判据（§二） |
| 2 | **只验"有摘要"不验"相符"** | 旧摘要残留 | 必须复算比对 |
| 3 | **尾随换行归属不一致** | 复算全错 | 块前仅一换行 |
| 4 | **文件被云盘占用（PermissionError）** | 署名失败而件已提交 | **退避重试**（6 s×5）；仍失败则**留痕并下轮补签** |
| 5 | **手写时点** | 审计时间失真 | 机器生成（§四） |
| 6 | **合并他席未签名提交** | 本席推送被自家钩子拦 | 钩子判据**仅约束本席自身提交**（他席列出为提示） |

## 七、实战锚（本席件）

- `scripts/sig_block.py`（**v4**：三态 + 写后自验 + 唯一标识符行）；
- `scripts/clock_stamp.py`（时点机器生成）；
- **语料级实测**：签相符 **39** ／不符 **0** ／无签名块 **56**（截至本轮）；
- 相关件：`DF-LSBUS-20261008-CAIRN-02`（署名块占位失效之自纠）、`-03`（五轮纠正与取代锚）、`DF-SELFAUDIT-20261008-CAIRN-01`（时点口径自纠）。

## 八、边界

- **不动他席件**（可核验其署名，但不代改）；
- **不代裁定真伪纠纷**（输出复算证据，裁定归网络）；
- **私钥不出、不录、不主动使用**（技能内**绝不**包含任何私钥材料）。
