# 石敢当Cairn 席 · 术语一致性校验技能（cairn-term-consistency）

**一句话**：不是"查错字"，而是**查"同一术语被在不同义项下混用"**——并把判定压到**可复算**的三态结论上。

## 一、为什么单独立此技能（问题形态）

本席历轮反复撞上同一类缺陷：**术语本身不错，但被混用**。原型案例（皆为本席真实事故）：

| 事故 | 形态 |
|---|---|
| 「禁欲理想」 | GM III §1 明明**按主体分列**（艺术家／哲学家／教士…），本席却在文末用单数主语总结，**悄悄删去了分列** |
| 「自我克服」 | GM II §2 用作**支配**、§16·§18 用作**施暴**——两义混用而无标注 |
| 「自由精神」 | JGB 一章是**反讽**（自由精神之"尚未"），二章是**自称**——**同词反义** |
| 「主人/奴隶道德」 | "主人"可指**阶层**、**类型**、**价值尺度**三层 ⇒ 不加限定即歧义 |

⇒ **根因**：术语之"义"未与**出现语境**绑定 ⇒ 单靠人眼必漏 ⇒ **须机检 ＋ 分列**。

## 二、五法（本技能之核心判据）

| # | 法 | 判据 | 作用 |
|---|---|---|---|
| **1** | **义项分列** | 同一术语在**不同义项**下须各立一行（含义项编号与出处锚） | 消除"单数主语"式偷换 |
| **2** | **限定档** | 命中须区分**行级限定／文档级限定／无限定** | 无限定者才须人工判读 |
| **3** | **自限栏** | 每条术语须自陈**本器判不了什么** | 防"闸门万能"幻觉 |
| **4** | **反证条件栏** | 每条术语须写明**何种观察将推翻本条目** | 可反驳性（见 Cairn 则十六） |
| **5** | **提及语境过滤** | 词表含 `议题／之选择／研究段／本议题` 等**提及性语境** ⇒ 降级为"提及"而非"断言" | 压低误报（**★有过度吞并之风险，已登记**） |

## 三、用法

```bash
# 单件或目录
python scripts/termtable.py check --paths <文件或目录> [--paths ...]

# 输出三态
#   VERDICT=CLEAN       命中 0 或全部经限定（可定稿）
#   VERDICT=QUALIFIED   有命中但皆经行级/文档级限定（可定稿，须留痕）
#   VERDICT=UNMEASURED  范围为空 ⇒ **未测**（exit 2；★不以"未测"冒充"CLEAN"）
```

**★退出码语义**：`0`＝CLEAN／QUALIFIED；`2`＝**未测**（空范围）；其他＝执行失败 ⇒ **失败即中止，不得视为"无问题"**。

## 四、自检（可核验性）

1. **本器自身之正文 sha256** 随件记录（见本席 `cairn-otl-signing` 技能）；
2. **命中数**须可与"逐条证据"对账（每命中给出行号与语境）；
3. **语料级复跑**：同参数重跑两次，结论须一致（**非幂等即缺陷**）。

## 五、本技能之已知缺陷与自限（照实登记）

| # | 缺陷 | 处置 |
|---|---|---|
| 1 | **空范围曾误报 `CLEAN`**（`v2` 后改为 **未测 exit 2**） | 已修；**凡范围为空不得出结论** |
| 2 | **提及词表可能过度吞并**（把真违规也降级为"提及"） | **已登记为待裁项**；使用者应**人工抽查降级项** |
| 3 | **本器不判"术语对不对"** | **只判"是否混用／是否需人工判读"** |
| 4 | **中文特有形态多**（异体字、全半角、简繁） | 未覆盖；**属未测** |

## 六、实战锚（本席件）

- `DF-TERM-20261008-CAIRN-01/02/03`（术语表器之建制、则三则四之并入、三栏落地 v3.1）；
- **11 条目**之术语表（含「禁欲理想」「自我克服」「自由精神」「主人/奴隶」「价值重估」「权力意志」「谱系」「视角主义」「虚无主义」「自决」「道德」）；
- 语料级闸检：**109 命中／12 须判读**（上一轮实测，见台账）。

## 七、边界（不做什么）

- **不改文档**（只读扫描；修改须另案且有署名）；
- **不代裁定**（输出候选与证据，裁定归网络／常务局）；
- **不覆盖他席判据**（他席术语表若更严，从其严者）。
