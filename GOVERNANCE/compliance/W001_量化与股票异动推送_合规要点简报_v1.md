## 一、一句话定性

本项目合规与否的**唯一分水岭**是：推送内容是否构成「就**具体证券投资品种**提供**投资分析意见、价格走势预测、品种选择建议或买卖时机建议**」。仅做**客观数据 / 异动监测 / 量化指标呈现**（历史数据、成交量、涨跌幅、换手率等事实性陈述），不落入证券投资咨询；一旦叠加「买入/卖出/关注/持有」或「预测涨跌 / 推荐个股」，即跨入证券投资咨询红线。

## 二、荐股红线：定性边界与规避要点

**法律锚点（真实检索，现行有效）**

- 《中华人民共和国证券法》第一百六十条：从事证券投资咨询服务业务，应当经国务院证券监督管理机构核准；未经核准，不得为证券的交易及相关活动提供服务。
- 《证券、期货投资咨询管理暂行办法》（证委发〔1997〕96 号）第二条：证券期货投资咨询，指为投资人提供证券期货投资**分析、预测或建议**等直接或间接有偿咨询服务的活动；第三条：必须取得中国证监会业务许可。
- 《关于加强对利用「荐股软件」从事证券投资咨询业务监管的暂行规定》（证监会公告〔2020〕66 号）第一条：具备下列任一项功能的软件即属「荐股软件」——（一）提供涉及具体品种的投资分析意见或预测价格走势；（二）提供具体品种选择建议；（三）提供具体品种买卖时机建议；（四）其他投资分析、预测或建议。**仅具备证券信息汇总或历史数据统计功能、不具备上述四项的，不属于「荐股软件」。**

**定性边界（可直接套用）**

| 推送内容 | 定性 |
|---|---|
| 个股涨跌幅、成交量、换手率、龙虎榜、异动时间点等客观事实 / 历史数据 | 不构成投资咨询（信息汇总 / 统计） |
| 量化指标数值本身（因子值、波动率、乖离率等）的客观计算展示 | 一般不构成（数据统计） |
| 「预测该股将上涨 / 下跌」「目标价 X 元」「建议买入 / 卖出 / 持有 / 关注」 | 构成投资咨询，需牌照 |
| 「该股符合 XX 策略、值得介入」「异动是机会」等指向性 / 诱导性判断 | 构成投资咨询，需牌照 |
| 由指标自动生成的「买卖点信号」「金叉死叉提示」 | 高风险，可能被认定为买卖时机建议 |

**规避要点（可执行）**

1. 推送只保留**事实陈述与统计**，删除一切「建议、预测、推荐、买卖时机、目标价、涨跌判断」类表述。
2. 对「异动」只描述「发生了什么」（时间、幅度、量能），不解释「意味着什么、该不该做」。
3. 若必须呈现策略结果，只呈现**历史回测的客观统计**（胜率、收益率的过往分布），并显著标注「历史表现不代表未来，不构成投资建议」。
4. 避免「直接或间接有偿」形态下叠加建议——免费客观信息相对安全，一旦收费 / 获利且内容含建议，风险陡增。
5. 不得以「量化信号」「智能选股」等名义，实质输出个股买卖点或推荐清单。

**佐证案例（入库案例）**：廖某强非法经营案——以「证券知识培训」为幌子，实质向公众提供大盘 / 板块趋势分析预测并提示个股买卖点，被认定为非法经营证券投资咨询业务（非法经营额 5 亿余元，违法所得 9100 余万元）。教训：**外衣不改变实质**，关键看是否「就具体品种走势 / 可行性提供分析、预测或建议，直接影响投资决策」。

## 三、收益承诺禁区：禁止承诺收益 / 保本的表述限制

**法律锚点**

- 《证券、期货投资咨询管理暂行办法》第二十四条：投资咨询机构及人员不得向投资人**承诺证券期货投资收益**。
- 《证券投资顾问业务暂行规定》（证监会公告〔2010〕27 号）第二十四条：禁止对服务能力和过往业绩进行虚假、不实、误导性营销宣传，**禁止以任何方式承诺或者保证投资收益**。
- 《中华人民共和国证券法》第一百六十一条：投资咨询机构及从业人员不得与委托人**约定分享证券投资收益或者分担证券投资损失**。
- 《证券投资咨询机构执业规范（试行）》第二十条（自律规则）：不得向客户**承诺确定收益或收益范围**；不得使用「安全、保证、承诺、保险、避险、有保障、高收益、无风险」等可能使投资者认为没有风险的表述。

**禁止表述清单（可直接执行，出现即违规）**

- 收益承诺类：「保本」「保收益」「稳赚」「稳赚不赔」「包赚不赔」「年化收益 X%」「保证盈利」「零风险」「无风险」。
- 收益暗示类：「跟着买不会亏」「目标收益 X%」「月收益可达 X%」「历史胜率 100%」（夸大历史业绩）。
- 变相担保类：「亏了包赔」「兜底」「回本承诺」「收益共享、亏损共担」。
- 夸大业绩类：以特定客户 / 特定时段最佳收益作为「历史业绩」宣传而未明示。

**风险提示**：即便不直接说「保本」，只要表述使投资者产生「无风险 / 稳赚」的合理认知，即可被认定为变相承诺收益——证监会执法口径以「误导性」为审查核心。

## 四、《证券法》资质边界：无牌照推送个股信息的合规风险

**法律锚点**

- 《中华人民共和国证券法》第一百六十条：证券投资咨询服务业务须经国务院证券监督管理机构**核准**。
- 《证券、期货投资咨询管理暂行办法》第三条、第十二条：须取得证监会**业务许可**；从业人员须取得从业资格并加入有资格机构。
- 《证券投资顾问业务暂行规定》第七条：提供投顾服务的人员须具有证券投资咨询**执业资格**，并在中国证券业协会**注册**为证券投资顾问。
- 《关于加强对利用「荐股软件」从事证券投资咨询业务监管的暂行规定》第二条：向投资者销售或提供「荐股软件」并直接或间接获取经济利益的，属从事证券投资咨询业务，须经许可；未取得资格，任何机构和个人不得利用荐股软件从事证券投资咨询业务。

**无牌照推送个股信息的风险链（可执行结论）**

1. **行政风险**：被证监会及派出机构认定为非法证券投资咨询，面临责令停止、没收违法所得、罚款；若通过自媒体编造 / 传播虚假或误导性信息，另依《证券法》第五十六条、第一百九十三条处罚（没收违法所得并处 1–10 倍罚款；无违法所得或不足 20 万元的，处 20 万–200 万元罚款）。
2. **刑事风险**：情节严重的，可能以**非法经营罪**追究刑事责任（廖某强案即以非法经营罪定罪）。
3. **民事风险**：《证券法》第一百六十一条——投资咨询机构及从业人员违反禁止行为给投资者造成损失的，依法承担赔偿责任。
4. **传导风险**：若运营方自身或关联方同时进行证券交易，须警惕《证券法》第五十五条第（六）项「对证券、发行人公开作出评价、预测或者投资建议，并进行反向证券交易」构成操纵市场的风险。

## 五、综合合规结论与执行建议

1. **守住「客观数据」边界**：W-001 若要无牌照合规运营，推送内容必须严格限定为「证券信息汇总 + 历史数据统计」，删除一切投资分析意见、走势预测、品种选择建议、买卖时机建议。
2. **资质与内容双轨**：若业务方向必须包含个股建议 / 信号，唯一合规路径是取得证券投资咨询业务资格（机构牌照），并由具执业资格且注册的证券投资顾问出具——需提前评估是否具备该条件。
3. **表述零承诺**：全链路（产品文案、推送文案、客服话术、营销物料）执行上述「禁止表述清单」审查，杜绝任何承诺 / 暗示收益、保本、无风险字样。
4. **信息真实客观**：推送的「异动」信息必须真实、客观、可溯源，杜绝编造或误导性信息（《证券法》第五十六条）。
5. **留痕与提示**：所有推送附统一风险提示「历史 / 数据表现不代表未来，不构成投资建议；市场有风险，投资需谨慎」，并留存推送时间、内容、依据等记录。
