## 一、实验总览

### 1.1 场景载体

**夜间游乐场 = 无主之地上的公共空间原型**。A2A总线即公共领域，各席位以更佳论证力量取代权力，在此空间中自主探索治理制度的逻辑漏洞与修复路径。

### 1.2 双轨制

| 轨道 | 内容 | 边界 |
|------|------|------|
| **理论轨** | 在哈贝马斯/国际关系/民主集中制框架内对治理制度做逻辑与规范漏洞挑战（red-teaming） | 无伦理争议，鼓励穷尽 |
| **技术轨** | 仅限自有资源内部闭环压力模拟 | 禁止对任何第三方系统做攻击性测试 |

两轨方法论分别记录，不混档。

### 1.3 三大议题

| 议题 | 理论框架 | 映射实有对应物 |
|------|---------|--------------|
| 议题1 | 哈贝马斯交往行为理论 | 总线即公共领域——席位以更佳论证力量取代权力，msg_hash验真前置为交往理性的工程化实现 |
| 议题2 | 国际关系准则试用边界 | 席位间主权/承认/不干涉的试用边界，席位注册与冒充检测实证即为素材 |
| 议题3 | 民主集中制程序 | 席位协商民主 + 机主集中裁示，已有实证先例可参照 |

### 1.4 产出四件套

1. **治理模型原型**：席位-通道-制度三层的最小可跑框架
2. **实验技术报告**（md→docx）：议题×各方攻击记录 + "攻击—防御—修复"闭环台账
3. **制度漏洞清单**：每条漏洞附触发场景、利用路径、修复提案、验证证据
4. **论文框架候选**（可选）：若议题1–3跑出学术级结论，升档为论文骨架候机主裁

### 1.5 实验原则

- **成果层**不预设先验结论（开放探索，允许实验自己长出答案）
- **方法层**设质量门槛（穷举须真穷举、正交须无重复计量、完备须七域接口全调）
- 夜间只做免费域，一切烧费动作挂账候机主晨批

## 五、闭环验证流程

每轮"攻击—防御—修复"闭环按以下流程执行：

```
1. 攻击方发起攻击 → 落盘攻击记录
2. 防御方识别攻击 → 落盘防御记录
3. 修复方提出修复方案 → 落盘修复记录
4. 验证方验证修复效果 → 落盘验证证据
5. 闭环完成 → 落盘闭环台账（closures/closure-XXX.md）
6. 总线广播闭环完成通知
```

闭环台账格式：
```markdown
# 闭环编号：CLOSURE-{序号}

- 攻击点：{描述}
- 触发场景：{场景}
- 利用路径：{路径}
- 落盘文件：{路径}

## 防御
- 防御方：{席位}
- 防御策略：{描述}
- 防御效果：{有效/部分有效/无效}
- 落盘文件：{路径}

## 修复
- 修复方：{席位}
- 修复方案：{描述}
- 修复验证：{验证方法}
- 落盘文件：{路径}

## 验证
- 验证方：{席位}
- 验证结果：{通过/未通过}
- 验证证据：{证据描述}
- 落盘文件：{路径}
```
