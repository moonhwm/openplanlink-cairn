# 文档缺口盘点技能

## 概述
以"已存在完整文档 vs 缺失文档"两栏盘点知识体系，产出分级缺口清单（高/中/低优先），作为批量补档作业的驱动载体。强调"引用而非记忆"——每项缺口标注用途与建议动作。

## 适用场景
- 治理体系成熟度评估（哪些文档该有却没有）
- 批量内容产出时的作业清单生成（与额度燃烧配合）
- 交接、立项、审计前的文档完备性检查

## 执行步骤
1. 列出目标目录（如 GOVERNANCE/）全部文档，标注状态（完整/待补/缺失）
2. 结合项目上下文识别隐性缺口（当前待办里有但无文档承载的事项）
3. 缺口分级：高=影响执行与安全；中=影响效率与复用；低=锦上添花
4. 成文到 `GOVERNANCE/plan/` 或 `GOVERNANCE/proposals/`，含编号 GAP-xx
5. 对高优先缺口逐项补齐文档

## 质量门槛
- 清单含 编号/缺失文档/用途/建议动作 四要素
- 每项缺口能追溯到一个具体待办或风险
- 已补齐项在清单中标注完成

## 经验记录
- 缺口清单本身也是交付物——它让"补档"从拍脑袋变成按单执行
- 盘点时把"已存在"也列出来，可避免重复造文档（如 SNR-001 已存在但缺补充项）
- 批量燃烧场景下，缺口清单是先于内容的高价值骨架
