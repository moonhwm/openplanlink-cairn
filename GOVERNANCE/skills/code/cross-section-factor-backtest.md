# 横截面因子分组与动量策略回测

## 适用场景

当需要评估某个因子（如动量、波动率）在全市场股票池上的预测能力时，使用横截面因子分组方法。具体步骤：按因子值排序等量分5档，计算各档前向收益差（Q5-Q1），判断因子方向性。进一步可构建多空组合（做多Q5/做空Q1）做纸面回测。

## 核心方法

### 1. 因子计算

从全市场日线JSON数据中为每只股票构建时间序列，计算以下因子：

- **动量因子**：mom_kd = Π(1+ret_i) - 1（近k交易日几何累计收益）
- **反转因子**：rev_kd = -mom_kd（与动量完全负相关，冗余）
- **波动率**：vol_ann = stdev(日收益) × √252
- **最大回撤**：在价格收益指数上算（免疫除息跳空）
- **成交额**：amt_mean = 区间日均成交额

**关键细节**：收益率用 pre_close 基准（交易所口径），免疫除息跳空。价格收益指数由 ret 累乘构建，在其上算最大回撤避免除息污染。

### 2. 横截面分组

按因子值排序等量分5档（Q1=最低 ~ Q5=最高），统计各档平均前向收益。Q5-Q1 收益差 > 0 表示因子正向（高因子值股次日跑赢），< 0 表示负向。

### 3. 多空组合回测

每个交易日：用前window天收益算动量 → 排序分5档 → 做多Q5等权/做空Q1等权 → 计算每日多空收益 → 统计累计收益/年化收益/夏普比率/最大回撤/胜率。

**关键细节**：动量计算窗口需比回测窗口多1天（前window+1天算动量，当日算持仓收益），避免前视偏差。

## 实测结论（2026-09-29，82交易日，5574只股票）

| 因子 | Q5-Q1 收益差 | 方向 | 回测夏普 |
|---|---|---|---|
| 5日动量 | +2.12% | 正向 | 0.42 |
| 10日动量 | +1.12% | 正向 | 0.87 |
| 20日动量 | +12.81% | 正向 | 1.59 |
| 年化波动率 | -2.02% | 负向 | — |
| 日均成交额 | -1.78% | 负向 | — |

**关键发现**：
- 20日动量（月度）策略表现最优，夏普1.59
- 低波动异象显著（高波动股次日更差）
- 动量与波动率近乎零相关（独立因子）
- 反转因子 = -动量因子（完全冗余）
