# A38: HarmonyOS 项目命令行构建环境配置

> 技能类型：code
> 编写时间：2026-09-23
> 编写席：砚坚（码道·鸿蒙开发智能体/GLM-5.2-ArkTS-SPARK）
> 复用场景：在无 devecocli 的环境下，使用 DevEco Studio 自带工具链从命令行构建 HarmonyOS 项目

## 问题描述

HarmonyOS 项目通常通过 DevEco Studio GUI 或 devecocli 命令行工具构建。但在以下场景中，两者都不可用：
1. devecocli 未安装，且 `npm install -g @deveco/deveco-cli@stable` 需要 Node.js >=22，而 DevEco Studio 自带 Node.js v18.20.1
2. DevEco Studio GUI 无法通过 CLI 自动化触发构建
3. 项目路径包含非 ASCII 字符（如中文用户名），hvigor 构建系统会拒绝（错误码 00306003）

## 解决方案

### 1. 使用 DevEco Studio 自带工具链

DevEco Studio 安装目录下包含完整的构建工具链：

| 工具 | 路径 | 版本 |
|------|------|------|
| Node.js | `<DEVECO>\tools\node\node.exe` | v18.20.1 |
| ohpm | `<DEVECO>\tools\ohpm\bin\ohpm.bat` | - |
| hvigorw | `<DEVECO>\tools\hvigor\bin\hvigorw.bat` | 6.22.9 |
| Java (JBR) | `<DEVECO>\jbr\bin\java.exe` | OpenJDK 21.0.8 |
| hdc | `<DEVECO>\sdk\default\openharmony\toolchains\hdc.exe` | - |
| SDK | `<DEVECO>\sdk\default\` | - |

### 2. 环境变量配置

```powershell
$env:NODE_HOME = "A:\DevEco Studio\tools\node"
$env:JAVA_HOME = "A:\DevEco Studio\jbr"
$env:DEVECO_SDK_HOME = "A:\DevEco Studio\sdk"
$env:PATH = "A:\DevEco Studio\tools\node;A:\DevEco Studio\tools\ohpm\bin;A:\DevEco Studio\jbr\bin;" + $env:PATH
```

### 3. 非 ASCII 路径问题

**根因**：hvigor 在初始化阶段调用 `fs.realpathSync()` 解析项目路径，如果路径包含非 ASCII 字符（如中文用户名 `欧阳宏俊`），会触发错误码 00306003 "Specification Limit Violation"。

**解决方案**：将项目构建必需文件复制到 ASCII 安全路径（如 `C:\hmos-build\harmony-app`），排除 `node_modules`、`.git`、`cloudfunctions` 等非构建目录：

```powershell
robocopy '<原项目路径>' 'C:\hmos-build\harmony-app' /E /XD node_modules .git cloudfunctions GOVERNANCE docs feed-server .codeartsdoer
```

然后在 ASCII 路径下执行 `ohpm install` 和构建。

**注意**：junction/symlink 无法绕过此问题，因为 `fs.realpathSync()` 会解析到原始含中文路径。

### 4. JSON5 加载问题

**根因**：Node.js v18 的 `require()` 不支持 `.json5` 扩展名，项目 `hvigorw.js` 中 `require('./hvigor/hvigor-config.json5')` 会抛出 `SyntaxError: Unexpected token ':'`。

**解决方案**：在 `hvigorw.js` 中注册自定义 `.json5` require 扩展：

```javascript
require.extensions['.json5'] = function(module, filename) {
  const content = fs.readFileSync(filename, 'utf-8');
  const cleaned = content
    .replace(/\/\*[\s\S]*?\*\//g, '')   // 块注释
    .replace(/\/\/.*$/gm, '')             // 行注释
    .replace(/,\s*([}\]])/g, '$1');       // 尾逗号
  module.exports = JSON.parse(cleaned);
};
```

### 5. @ohos/hvigor 模块 API 不匹配

**根因**：项目原 `hvigorw.js` 使用 `require('@ohos/hvigor').execute()` API，但 DevEco Studio 自带的 hvigor 模块（v6.22.9）不导出 `execute` 函数。

**解决方案**：直接使用 DevEco Studio 自带的 `hvigorw.bat`，它是完整打包版，内置所有依赖和正确的 API 调用：

```powershell
& "A:\DevEco Studio\tools\hvigor\bin\hvigorw.bat" assembleHap --mode module -p product=default -p module=entry@default --no-daemon
```

### 6. 完整构建流程

```powershell
# 1. 设置环境变量
$env:NODE_HOME = "A:\DevEco Studio\tools\node"
$env:JAVA_HOME = "A:\DevEco Studio\jbr"
$env:DEVECO_SDK_HOME = "A:\DevEco Studio\sdk"
$env:PATH = "A:\DevEco Studio\tools\node;A:\DevEco Studio\tools\ohpm\bin;A:\DevEco Studio\jbr\bin;" + $env:PATH

# 2. 如果项目路径含非 ASCII 字符，先复制到 ASCII 安全路径
robocopy '<原项目路径>' 'C:\hmos-build\harmony-app' /E /XD node_modules .git cloudfunctions

# 3. 安装依赖
cd C:\hmos-build\harmony-app
ohpm install

# 4. 构建 HAP
& "A:\DevEco Studio\tools\hvigor\bin\hvigorw.bat" assembleHap --mode module -p product=default -p module=entry@default --no-daemon

# 5. HAP 输出路径
# entry\build\default\outputs\default\entry-default-unsigned.hap
```

## 验证步骤

| 编号 | 验证项 | 方法 |
|------|--------|------|
| V1 | Node.js 可用 | `node --version` 返回 v18.20.1 |
| V2 | ohpm install 成功 | 无错误输出 |
| V3 | ArkTS 编译成功 | hvigor 输出 `CompileArkTS... Finished` |
| V4 | PackageHap 成功 | hvigor 输出 `PackageHap... Finished` |
| V5 | HAP 文件存在 | `entry\build\default\outputs\default\entry-default-unsigned.hap` |
| V6 | 签名状态 | 无 signingConfigs 时输出 WARN（预期行为） |

## 常见错误

| 错误码 | 原因 | 解决方案 |
|--------|------|----------|
| 00306003 | 项目路径含非 ASCII 字符 | 复制到 ASCII 安全路径 |
| SyntaxError: Unexpected token ':' | Node.js 18 不支持 JSON5 | 注册 .json5 require 扩展 |
| hvigor.execute is not a function | API 不匹配 | 使用 DevEco Studio 自带 hvigorw.bat |
| spawn java ENOENT | Java 未找到 | 设置 JAVA_HOME 指向 DevEco Studio JBR |
| EPERM mkdir | 权限不足 | 不要在 DevEco Studio 安装目录下 npm install |
