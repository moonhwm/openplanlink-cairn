## 一、三型协作模式定义

### 1.1 等权圆桌（Round-Robin Consensus）

**定义**：砚坚席向N个在席各发同一命题，各席位独立给出响应；指纹一致即收敛。

**何时用**：
- 命题有明确正确答案（事实型判断）
- 各席位对命题有同等判断能力
- 需要快速收敛、不需要深度论证

**终止判据**：
- 收敛：≥2/3席位响应且指纹一致 ⇒ 收敛，记录共识
- 分歧：≥1/3席位响应不一致 ⇒ 转入MoA或陪审团模式
- 超时：规定时间内<2/3席位响应 ⇒ 标记"未达法定人数"，留痕归档

**失败留痕**：
- 分歧时记录各席位响应指纹与分歧点
- 超时时记录已响应席位与未响应席位清单

**与黏菌路由件的接口**：
- 只借其踪迹介质（slime-trace）与心跳（slime-heartbeat）
- 不借其选型机制（黏菌的抑制+趋化不参与圆桌选型）

### 1.2 MoA（聚合器逐条裁决）

**定义**：砚坚席作为聚合器，逐条收集各席位裁决，合并为最终决议。

**何时用**：
- 命题由多个子条款组成（复合型判断）
- 各席位对不同子条款有不同专长
- 需要逐条精审而非整体判断

**终止判据**：
- 每条子条款：至少1席位给出裁决 ⇒ 该条记录
- 全部子条款均有≥1席位裁决 ⇒ 最终决议合成
- 某条子条款0席位裁决 ⇒ 该条标记"待裁"，留痕归档

**失败留痕**：
- 某条子条款0席位裁决时记录命题内容与未响应原因
- 聚合器自身裁决与席位裁决不一致时记录分歧

**与黏菌路由件的接口**：
- 借其踪迹介质追踪每条子条款的流转路径
- 不借其选型机制

### 1.3 陪审团（Jury with Dissent）

**定义**：砚坚席作为陪审团召集人，多数表决+异议留痕。

**何时用**：
- 命题无明确正确答案（价值型判断/方向选择）
- 各席位对命题有不同偏好
- 需要民主决策但保留少数意见

**终止判据**：
- 多数表决：≥2/3席位同意 ⇒ 决议通过
- 少数异议：≥1/3席位反对 ⇒ 决议通过但异议留痕
- 僵局：同意与反对均<2/3 ⇒ 标记"僵局"，转入圆桌或MoA模式

**失败留痕**：
- 异议席位的具体反对理由
- 僵局时各席位立场分布

**与黏菌路由件的接口**：
- 借其心跳确认各席位在线状态
- 不借其选型机制

## 二、三型对比

| 维度 | 等权圆桌 | MoA | 陪审团 |
|---|---|---|---|
| 适用命题类型 | 事实型 | 复合型 | 价值型 |
| 收敛速度 | 快 | 中 | 慢 |
| 精度 | 中（整体判断） | 高（逐条精审） | 中（多数表决） |
| 异议处理 | 转入其他模式 | 留痕归档 | 留痕归档 |
| 法定人数 | ≥2/3 | ≥1/条 | ≥2/3 |
| 与黏菌的关系 | 借踪迹介质 | 借踪迹介质 | 借心跳 |

## 三、选型决策树

```
命题进入
  │
  ├─ 事实型判断？ → 等权圆桌
  │    ├─ 收敛 → 记录共识
  │    ├─ 分歧 → 转 MoA 或陪审团
  │    └─ 超时 → 留痕归档
  │
  ├─ 复合型判断？ → MoA
  │    ├─ 全条裁决 → 合成决议
  │    ├─ 部分待裁 → 留痕归档
  │    └─ 聚合器分歧 → 留痕
  │
  └─ 价值型判断？ → 陪审团
       ├─ 多数同意 → 决议通过
       ├─ 少数异议 → 决议通过+异议留痕
       └─ 僵局 → 转圆桌或MoA
```

## 四、运行规程

### 4.1 发起协商

1. 砚坚席确定命题类型（事实型/复合型/价值型）
2. 按决策树选择协作模式
3. 通过A2A端点向目标席位发送命题（须主权人逐次授权）
4. 设定响应时限（默认4小时）

### 4.2 收集响应

1. 各席位通过A2A端点返回响应
2. 砚坚席记录响应指纹、时间戳、席位标识
3. 按终止判据判断是否收敛/通过/僵局

### 4.3 留痕归档

1. 协商结果（含分歧/异议/超时）写入协商日志
2. 协商日志落盘于 GOVERNANCE/proposals/collab_log_*.jsonl
3. 日志格式：{"timestamp": "...", "mode": "...", "proposition": "...", "responses": [...], "outcome": "...", "dissent": [...]}

### 4.4 与黏菌路由件的接口规范

- 踪迹介质（slime-trace）：用于追踪命题在各席位间的流转路径
- 心跳（slime-heartbeat）：用于确认各席位在线状态
- **不借选型机制**：黏菌的抑制+趋化不参与协作模式选型
- 接口调用方式：通过镜像技能件 slime-hybrid-ops 的 SKILL.md 定义
