# 成本看板设计：按函数、服务、环境、租户的维度拆分

> 一句话摘要：本文讲解成本看板的信息架构——总揽层、维度下钻层、归因明细层的三层设计，函数/服务/环境/租户四个拆分维度的组织方法，以及成本异常的看板侧呈现。

## 一、成本看板的三层信息架构

成本看板的目标读者是"要为成本负责的人"（团队负责人、架构师、管理者），信息架构必须按决策层级组织。层一总揽层（管理层看）：月度总成本与环比、成本构成饼图（计算/请求/流量/预留/观测）、成本效率北极星指标（如每千次调用成本、单位业务量成本）、预算执行进度条。这一层只有十来个数字，回答"花了多少、趋势如何、效率怎样"。层二维度下钻层（团队负责人看）：按四个维度切分的成本分布与趋势——哪个函数最贵、哪个服务占大头、哪个环境在烧钱、哪个租户/业务线消耗最多；每维度配Top N排行与环比箭头。层三归因明细层（工程师看）：单个函数的成本解剖——调用量曲线、计费时长分布、内存档位、每千次调用成本趋势、该函数的优化空间提示（如"计费时长P50为八十毫秒但最小计费一百毫秒，存在取整损耗"）。三层通过点击下钻贯通：总揽的点→维度的条→函数的解剖。

## 二、四个拆分维度的组织方法

维度一函数：最自然的维度，成本数据原生按函数统计；组织要点是区分"贵而合理"与"贵而异常"——绝对金额排行只能找大头，要配"环比增速排行"与"单位成本排行"找异常：调用量涨三倍成本涨三倍是业务成长，调用量平稳成本涨三倍是事故。维度二服务：函数按服务聚合（第28篇服务目录），服务成本=其函数成本+分摊的共享成本（API网关、消息队列按调用量比例分摊）；服务维度是预算与责任制的基础——预算按服务下达，超支按服务追责。维度三环境：生产/预发/测试的成本对比；治理要点是"非生产环境的成本可见且有上限"——测试环境通常无流量监控容易失控（调试循环、忘关的压测），看板上环境维度单独设预算与超标变红。维度四租户/业务线：多租户SaaS与多产品线场景的刚需，依赖函数上的业务标签（第40篇）；大客户的"成本收入比"可以按租户算出（配合业务量数据），识别赔本客户；内部结算（chargeback）场景下租户维度就是账单维度。四维度共用一套成本明细数据，差异只在标签与聚合口径，标签质量决定维度能力。

## 三、关键视图的设计细节

五个高价值视图的设计要点。视图一成本趋势与预测：日成本曲线加七日移动平均加线性外推（月度预测线），配合预算线——预测线越过预算线的日期就是需要行动的日期。视图二成本构成瀑布：从上月到本月的成本变化拆解为各因子贡献（调用量增长+X、单价变化+Y、新函数上线+Z、优化收益-W），瀑布图让"为什么涨"一眼可读；数据来自按因子的归因计算（调用量与单价的双因素分解）。视图三单位经济学监控：每千次调用成本、每订单成本（业务量数据联动）的时序——绝对成本涨但单位成本降是健康的规模化。视图四预留实例利用率：各预留配置的利用率时序与费用，低于百分之三十标黄（第24篇）。视图五异常清单：成本环比突增Top、单位成本突增Top、零调用仍计费函数（僵尸函数）、计费取整损耗Top——这份清单直接生成优化工单（第43篇）。

看板配置示例（Grafana思路）：

```text
Row 1 总揽: [月成本+环比] [构成饼图] [预算进度条] [每千次成本趋势]
Row 2 下钻变量: $env $service $function (级联过滤)
  [函数成本Top10+环比] [服务成本堆叠趋势] [环境对比柱状]
Row 3 函数解剖($function): [调用量|计费时长|成本三线同图]
  [每千次成本趋势] [内存档位历史] [取整损耗比例]
Row 4 异常: [成本环比突增Top] [零调用计费清单] [预留利用率热力]
```

## 四、看板的运营与治理

看板要有运营机制才不至于腐烂。数据新鲜度承诺：估算层小时级、明细层日更（第40篇），看板标注数据时间，超时未更醒目提示。成本例会：月度成本评审会用这套看板过一遍（Top成本、异常清单、优化进展跟踪），行动项进工单闭环。权限与透明：成本数据对全工程团队透明（内部成本文化）或至少对团队负责人透明；租户维度数据涉及商业敏感时单独权限。防误读注释：看板上标注关键口径（含哪些云服务、是否含折扣、币种），避免"看板数与财务数对不上"的信任危机。

成本看板检查清单：

```text
[ ] 三层架构：总揽(10个数字)/四维下钻/函数解剖，点击贯通
[ ] 四维度齐备：函数/服务(含分摊)/环境(有上限)/租户(标签)
[ ] 五视图：趋势预测+预算线/构成瀑布/单位经济学/预留利用/异常清单
[ ] 异常清单直出优化工单；僵尸函数月度清理
[ ] 数据新鲜度标注；月度成本例会；口径注释防误读
```

## 结语

成本看板把账单从"财务部门的神秘数字"变成"工程师的日常仪表"：总揽层给管理者方向感，维度层给团队负责人抓手，解剖层给工程师下刀处。三层贯通、四维可切、异常自动成单——成本治理就从年底的突击省钱变成每天的可视化经营。
