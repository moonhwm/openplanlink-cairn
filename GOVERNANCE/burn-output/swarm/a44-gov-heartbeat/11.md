# 11. Quorum视角下的存活判定：多数派如何定义节点生死

> 摘要：本文解释为什么单一观察者的存活结论不可信，阐述quorum存活判定的语义、观察者集合的选取、票数计算与判定流程，分析脑裂防护原理并给出实现要点与清单。

## 一、单一视角的根本缺陷

异步网络中，"节点死了"与"我和节点之间的网络断了"在观察者本地不可区分。这是分布式系统最基础的困境之一：无论等待多久，观察者都无法确定对端是崩溃还是报文在途中丢失。因此任何单观察者的失联结论本质上都只是"从我的视角看失联"，把它当作全局事实使用，就会在网络抖动或观察者自身网络故障时产生误判，进而触发错误的切换动作。轻则无谓重启，重则双主脑裂、数据分叉。要获得接近全局的结论，必须汇聚多个独立观察者的视角——这正是quorum存活判定的动机。

## 二、Quorum判定的语义与数学基础

设观察者总数为N，某节点的失联结论至少需要Q个观察者同时报告才成立。当Q大于N的一半时，任何两个不同的多数派集合必然相交——因为两个大小都超过半数的集合不可能不相交。这个交集性质带来两个关键保证：其一，失联结论不可能同时由两个不相交的观察者小组分别成立，从而杜绝了小组A判定节点死、小组B判定节点活的双结论并存；其二，配合观察者自身的选举或租约机制，可以保证同一时刻至多一个决策主体拥有执行权。这就是quorum防脑裂的数学骨架。工程上Q通常取N/2加一，例如三个观察者取两票，五个取三票。观察者数量建议取奇数：偶数集群在半数观察者同时故障时会出现无法达到多数的僵局，而奇数集群同样规模下可用性更高。

需要注意quorum判定改变的是结论的置信度语义，而不是检测速度本身：各观察者依然独立做本地检测（超时或Phi阈值），quorum层只是汇聚。从节点失效到结论成立的总延迟等于：最慢的第Q名观察者的本地检测延迟，加上一轮汇聚投票的通信延迟。因此quorum体系的总延迟由"第Q百分位观察者"决定，压低单个观察者的阈值意义有限，更重要的是让各观察者的检测延迟分布尽量收敛。

## 三、判定流程设计

```text
# quorum存活判定流程
角色: 观察者若干(各自独立超时判定) + 协调者(可由观察者中选出)
1. 观察者i本地判定节点n失联 -> 向协调者报告(n, i, suspect, 证据摘要)
2. 协调者收到首份suspect后发起投票:
   QUERY(n) -> 广播给所有存活观察者
3. 各观察者在限定窗口内回复 live / suspect / unknown
4. 计票:
   suspect票数 >= Q        -> 判定 n 失联(客观失联), 进入处置流程
   live票数   >= Q          -> 判定 n 存活, 首报观察者记为本地网络问题
   两者都不足Q              -> 保持疑似, 窗口后重投, 连续r轮无果则告警观察者网格自身异常
5. 处置动作(切换/隔离)必须由持有租约的唯一协调者执行
```

流程中的细节决定成败。投票窗口要大于观察者间通信的P99往返，窗口过短会让慢回复等价于弃权，系统性拉低票数；观察者对自身无法判定的对象应回复unknown而非默认susppect，防止犹豫被计成指控；协调者本身故障时投票必须能被新协调者接管，已发起的投票记录需持久化或可重建，避免协调者更替造成判定悬空。

## 四、观察者集合的选取原则

观察者的独立性直接决定quorum的有效性。第一，故障域独立：观察者应跨机架、跨可用区部署，避免一个交换机故障导致多数观察者同时失明，此时quorum不仅失效还会制造"全体一致误判"的假象。第二，判定路径独立：各观察者到被判定节点的网络路径尽量不重叠，可结合拓扑感知选路。第三，观察者自身健康参与计票资格：只有自身处于存活状态的观察者其票才计入分母，观察者的观察者的监督链在此接入。第四，规模与延迟的平衡：观察者不必是全体节点，通常三到七个专职或兼职观察者即可，过多观察者徒增汇聚延迟与流量。

## 五、失效模式与防护

quorum判定体系自身的失效模式需要专门防护。僵局失效：可达票数永远不足Q，多因观察者大规模故障或网格分裂，此时应停止判定新失联并告警"判定体系降级"，绝不能自动降为少数派判定——降级通道一旦存在，脑裂防护即形同虚设。观察者分裂：两个小组各自认为对方失联，需依赖观察者层的仲裁机制（第三方站点或共享锁）裁决，生产环境常用的做法是引入一个极简的外部仲裁者，只在小组成员完全对等时投出关键一票。票数漂移：观察者扩缩容期间分母变化，投票必须携带观察者集合的纪元号，纪元不一致的票作废重投。

## 六、落地检查清单

- 失联结论与处置动作分离：quorum只产出结论，动作由持租约者执行；
- Q严格过半，观察者数为奇数，跨故障域部署；
- 投票窗口按通信分位数设定，回复区分live/suspect/unknown三态；
- 判定体系降级时只告警不降阈，少数派判定通道永久禁用；
- 观察者扩缩容走纪元号协议，旧纪元票作废；
- 定期注入"单观察者失明"用例，验证不产生全局误判；
- 注入"观察者小组分裂"用例，验证仲裁路径可用且不双判。
