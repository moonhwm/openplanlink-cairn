# 13. 租约机制与心跳的结合：Lease的授予、续期与过期

> 摘要：本文阐述租约如何为心跳体系提供带时间边界的信任：授予、续期、过期、让渡的生命周期设计，时钟不确定度对租期的影响，以及租约与故障切换、 fencing令牌的配合，并附实现要点。

## 一、租约解决什么问题

心跳只回答"节点看起来活着"，但分布式系统常需要更强的保证："在某个时间区间内，某节点被授权执行某动作，且全网有把握认为不会有第二个节点同时拥有该授权。"典型场景包括：领导者持有领导租约，租约有效期间无人挑战其地位；客户端持有配置监听租约，租约过期即失去临时资源；调度器持有隔离租约，防止在处置过程中资源被他人抢占。租约的本质是把"信任"物化为一个有时限的凭证：发放方承诺在租期内不把同一资源授权给他人，持有方必须在租期内完成续期否则授权自动作废。心跳与租约的关系是：心跳是原始信号，租约是把信号转化为可执行授权的机制；心跳证明活性，租约分配权力。

## 二、租约生命周期四阶段

授予阶段：发放方（通常是共识集群或仲裁服务）检查资源无有效租约后，写入租约记录，包含资源标识、持有者、租期长度、发放时间、单调递增的租约纪元号。纪元号是租约体系的核心防伪设计：每次新授予纪元加一，任何附带旧纪元的操作都会被资源相关方拒绝。续期阶段：持有者周期性（通常为租期的三分之一到一半）发起续期，续期成功则租期从当前时刻顺延。续期请求应携带纪元与进展摘要，发放方可据此拒绝假活节点的续期——心跳照发但工作计数停滞的节点，其续期应被驳回，这是租约对活性语义的自然扩展。过期阶段：发放方本地时钟越过租约截止时刻后，租约进入过期状态，资源可被重新授予。过期判定只能依据发放方自己的时钟，这是租约唯一权威性的来源。让渡阶段：持有者主动归还，常见于计划内停机，让渡应记录原因并把纪元推进，防止旧持有者用残留凭证继续操作。

## 三、时钟不确定度与租期设定

租约的安全性依赖一个微妙假设：持有者在租约到期后不会再认为自己仍持有。但持有者与发放方的时钟有偏差，租约还剩一秒时持有者发起的操作，可能在其本地看来仍在租期内、而在发放方看来已经过期。租期设计必须把时钟不确定度计入：持有者侧的安全操作期限应为租期减去最大时钟偏差减去操作耗时，发放方侧的重新授予应再推迟一个偏差余量。若系统使用NTP同步，偏差量级为毫秒到几十毫秒；若使用不确定度区间型时基（如TrueTime风格），不确定度是显式给出的，租期计算可以直接引用。经验公式：续期间隔小于租期的三分之一，最小安全余量大于两倍时钟不确定度加最大操作时长。租期本身则要覆盖从失效到重新授权的完整判定时间——租期短则故障接管快，但对抖动敏感；租期长则稳定但切换慢，这与心跳间隔的权衡一脉相承。

```text
# 租约时间线（发放方视角）
|<-------- 租期 T -------->|
发放(t0)  续期(t0+T/3)  续期(t0+2T/3) ... [持有者失效]
                                   t_dead = 最后续期 + T
发放方在 t_dead 后可重新授予(纪元+1)
持有者侧安全窗口 = 收到续期确认时刻 + T - 时钟偏差 - 操作耗时
纪律: 持有者绝不使用超过安全窗口的租约, 宁可提前主动放弃
```

## 四、租约与故障切换的配合

租约驱动的故障切换流程：跟随者发现领导者租约过期，不立即自行升级，而是先向发放方发起获取请求；发放方确认旧租约已过期后授予新租约并推进纪元；新领导者上任后，用自己的新纪元向所有资源相关方（存储后端、下游依赖）登记，旧领导者残留的带旧纪元的写请求被相关方以纪元校验拒绝。这套纪元校验机制就是fencing：它保证即使旧领导者因暂停而苏醒后继续写入，其写入也会因纪元过期被拒绝，从根上杜绝脑裂期的双写。心跳在其中的角色是让跟随者尽早发现领导者可疑（触发获取流程），而真正的安全边界由租约纪元保证——两者分工明确，心跳负责速度，租约负责正确性。

## 五、实现要点与陷阱清单

- 租约记录持久化在共识集群中，发放方自身故障不影响租约事实的有效性；
- 纪元号单调递增且全局可见，资源相关方强制校验纪号，旧纪元一律拒绝；
- 续期间隔为租期三分之一，续期失败立即进入放弃流程，不等到最后一刻；
- 持有者侧安全窗口显式计算，把时钟偏差与操作耗时计入，禁止用到最后一毫秒；
- 发放方重新授予前留出偏差余量，宁可延迟切换也不冒双持有风险；
- 假活节点的续期驳回条件（进展计数停滞）与活性检测阈值联动；
- 计划内让渡走独立接口并推进纪元，与过期区分记录；
- 所有租约事件（授予、续期、驳回、过期、让渡）全量落日志，可回放。

## 六、常见故障演练用例

租约机制的演练必须覆盖时钟类用例：持有者VM被冻结后恢复，验证其旧租约操作被fencing拒绝；发放方时钟被步进调整，验证过期判定不产生跳跃；续期报文在网络中延迟到过期后才到达，验证发放方按到达时刻处理并拒绝。此外要演练让渡与过期竞态：持有者正在让渡的同时第三方发起获取，验证纪元串行化不产生双授权。这些用例构成租约体系的回归防线，任何租期参数调整后都应重跑。
