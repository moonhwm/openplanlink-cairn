# 28. 间隔异常检测：变点检测与异常模式识别

> 摘要：本文讲解在心跳间隔序列上做异常检测的方法：从阈值检测到变点检测（CUSUM与滑动统计）、典型异常模式的形态识别（渐变、震荡、双峰）、以及把检测嵌入告警管线的工程要点。

## 一、从"超没超时"到"序列不对劲"

固定阈值与分位数基线回答的是"当前这一个间隔是否越界"，但许多严重问题在单点上毫不起眼：间隔从两百毫秒悄悄爬到四百毫秒，每个值都在阈值内，但系统性劣化已经发生；间隔方差从千分之五扩大到百分之八，抖动源已经出现；凌晨三点起间隔出现规律尖峰，某个失控的定时任务开始作祟。这类问题的信号在序列的统计特性变化里，而非单点越界里。间隔异常检测的对象因此不是单个样本，而是序列的分布参数——均值、方差、形状——随时间的变化。其目标是在劣化演变为失联之前，捕捉"行为变了"的早期征兆。

## 二、变点检测方法

变点检测回答"序列在何处发生了分布性质的改变"。工程实用三类。第一类，双速统计比较：第20篇的双速EWMA即其简化版——快估计对慢估计的显著偏离即候选变点，实现成本最低，适合作为第一道。第二类，CUSUM累积和：对标准化残差做累积求和，正常时累积和在零附近随机游走，均值漂移会让其持续单向累积，越过决策阈值即报变点。CUSUM对小幅持续漂移特别敏感——这正是单点阈值法最不擅长的场景，其参数（漂移容许量、决策阈值）决定灵敏度与误报的平衡，通常漂移容许量取一个标准差、阈值取十倍标准差量级起步再按ROC调优。第三类，窗口分布检验：对前后两个窗口的样本做秩和类非参数检验，分布形状变化（不只是均值）也能捕捉，计算稍重，适合低频离线扫描（每小时）与在线快扫形成互补。三类方法叠加的典型流水线：双速比较做秒级哨兵，CUSUM做分钟级确认，窗口检验做小时级复核，三者一致时置信度最高，仅哨兵触发时先入观察队列。

```python
# CUSUM变点检测(间隔序列)
class CusumChange:
    def __init__(self, mu, sigma, drift=1.0, thresh=10.0):
        self.mu, self.s = mu, sigma
        self.k, self.h = drift, thresh      # k:容许漂移 h:决策阈值
        self.pos = 0.0; self.neg = 0.0
    def update(self, x):
        z = (x - self.mu) / self.s
        self.pos = max(0.0, self.pos + z - self.k)   # 上行漂移累积
        self.neg = max(0.0, self.neg - z - self.k)   # 下行漂移累积
        if self.pos > self.h: self.pos = 0.0; return "UP"    # 间隔变大
        if self.neg > self.h: self.neg = 0.0; return "DOWN"  # 间隔变小
        return None
# 用法: mu/sigma取该对象基线; 连续3次UP -> 触发"渐变劣化"P3告警
```

## 三、异常模式形态库

除变点外，几类典型形态值得专门识别。渐变型：均值单向缓慢漂移（CUSUM的UP持续），典型成因是缓慢资源泄漏、路由劣化，处置指向容量与网络排查。震荡型：短周期大幅波动，方差骤增而均值稳定，典型成因是负载震荡、主备反复切换、GC边界效应，识别特征是窗口方差的变点而均值无变点。双峰型：间隔分布从单峰变双峰——一部分心跳快一部分慢，典型成因是双路径中的一条劣化（主备链路切换）、部分线程饥饿，识别靠分位数间距（P99与P50的比值）突然拉大。周期尖峰型：固定相位出现规律尖峰，成因是定时任务、批处理节奏，识别靠残差的周期频谱。周末型：低负载时段间隔特征整体变化，属正常模式切换而非异常，形态库应登记为已知模式，防止其反复触发变点告警——已知模式的白名单是形态库的必要组成。

## 四、嵌入告警管线的工程要点

分析结果进入告警体系要过三道转化。第一道，置信与分级：单一方法触发为疑似（P3观察），多方法一致或形态库匹配度高为确认（P3正式或P2），间隔异常类事件原则上不进P1——它属于预测性信号而非即时故障，除非伴随失联确认。第二道，归并与关联：变点事件与变更事件自动关联（变点时刻前后一小时的发布、配置变更清单附上），第26篇的上下文增益在此复用；同组对象同时变点归并为组级事件（又是拓扑归并思想）。第三道，反馈闭环：每条变点告警的结论（真劣化、误报、已知模式）人工标注回流，用于调参与形态库扩充，形成越用越准的循环。特别要防分析层的告警风暴：变点检测对分布参数敏感，基线重算、检测器重启、对象迁移都会产生伪变点，因此变点器自身必须感知这些体系事件并主动豁免对应时段。

## 五、验收与调参

异常检测的验收沿用ROC框架（第16篇）：用注入实验制造已知形态——限流注入制造渐变、抖动注入制造震荡、单路径劣化制造双峰——测量各形态的检出率与检出延迟；用两周正常数据测量误报率。合格基线参考：渐变型在均值漂移百分之三十时于十个周期内检出，震荡型在方差翻倍时于五个周期内检出，正常态误报每周不超过一次。参数调优的输入优先级：先降误报（提高阈值与确认次数）再提灵敏度——分析层告警的信噪比容错更低，因为它没有即时故障的紧迫性背书，一次误报消耗的信任要靠十次正确来偿还。

## 六、落地检查清单

- 双速哨兵、CUSUM确认、窗口检验复核三层流水线就位；
- 形态库覆盖渐变、震荡、双峰、周期尖峰四类，含已知正常模式白名单；
- 变点事件自动关联变更清单，同组归并，分析类事件不进P1；
- 体系事件（基线重算、迁移、重启）时段主动豁免伪变点；
- 检出结论人工标注回流，参数按季度复核；
- 注入验收覆盖四类形态，误报率与检出延迟入档；
- 分析层自身告警量纳入第26篇的预算制度管理。

## 七、小结

间隔异常检测把心跳体系从"事后判定失联"推进到"事前察觉劣化"。技术上以变点检测三层流水线为骨架，以形态库沉淀领域知识；工程上以保守分级、变更关联、反馈回流为纪律。它的价值不在替代失联检测，而在失联发生前的那个窗口里，为值班者争取到处置时间。
