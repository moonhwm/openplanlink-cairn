# 15. 网络分区下的存活判定与脑裂防护

> 摘要：本文分析网络分区对心跳体系的冲击：单视角失联的歧义、不对称分区、分区愈合后的状态冲突，阐述防脑裂的三道防线——quorum、租约纪元与fencing，并给出分区演练方案。

## 一、分区是心跳体系的试金石

网络分区指集群被割裂为互相不可通信的两组或多组。分区对心跳体系的冲击有三层。第一层是判定歧义：每个小组都只能看到自己这边的成员，对侧成员全部表现为失联，而这些"失联"节点在对方小组中可能完全健康。第二层是不对称分区：A到B的报文能通、B到A不通（单向黑洞），心跳有去无回，双方看到的世界完全不同。第三层是分区愈合后的冲突：分区期间两边各自做出的判定与操作，在愈合后需要合并，若两边都执行过排他性动作（比如各自选出了领导者），就产生了脑裂遗留问题。心跳体系的所有设计，最终都要在分区场景下接受检验：分区中不能双主，分区后能干净恢复。

## 二、分区中的判定纪律

分区期间的第一纪律是：失联结论必须携带视角。判定表述应为"从观察者O看节点N失联"，任何全局化表述（"N已死"）在分区中都是超载的断言。第二纪律是：小组不能仅凭自己的视角执行全局排他动作。少数派小组（成员数不过半）必须自我冻结——停止写操作、不发起选举、不产生全局性告警，只记录本地观察。多数派小组可以继续服务，但其判定也要意识到对侧可能存活。第三纪律是：不对称分区下，收到对方心跳的一方拥有更强的证据。若A组成员仍能收到B组某节点的心跳，说明该节点活着，只是回程不通；A组应把它标记为"半连通"而非失联。心跳报文设计为此应包含双向可达性摘要：节点声明"我最近能看到谁"，帮助对端区分"它死了"与"回程断了"。

## 三、防脑裂三道防线

第一道防线是quorum：任何全局排他角色（领导者、锁持有者）的取得都需要多数派成员的确认，分区必然产生少数派与多数派，少数派无法取得quorum即自动冻结。这是结构性防线，只要坚持不过半不授权，分区中就不可能出现两个合法权威。第二道防线是租约纪元：领导者等角色的权力附带租约，租约过期自动失效；新领导者产生时纪元加一。分区愈合后，旧侧的残留权威因租约已过期且纪元落后而自然作废。第三道防线是fencing：资源访问层（存储、下游服务）校验请求附带的纪元，拒绝旧纪元的操作。三道防线层层递进：quorum阻止新双主产生，租约让旧权威过期，fencing兜住已发生的旧权威操作。任何一道防线单独存在都不充分——只有quorum没有fencing时，分区期间旧主的长尾写入仍可能造成损害。

```text
# 分区期间的状态纪律(以领导者选举为例)
多数派小组: 可发起选举(获多数确认) -> 新租约纪元+1 -> 对外服务
少数派小组: 禁止选举; 领导者租约到期后自动降级为只读或静默
             持续尝试对外探测: 若能收到对侧任一成员心跳 -> 标记半连通
分区愈合:   双方交换纪元与任期记录 -> 高纪元者胜 -> 低侧回放日志补齐
             资源层fencing: 拒绝一切旧纪元写请求并计数上报
```

## 四、分区愈合与状态合并

分区愈合的处理常被忽视，却恰恰是事故高发环节。愈合后需要执行：纪元对账——所有节点交换各自见过的最高纪元与任期，收敛到全局最高值；操作日志合并——分区期间两侧各自执行的本地操作按全序重放，冲突操作按纪元与时间戳裁决并产生冲突报告；判定状态清零——分区期间产生的失联结论全部撤销，重新基于当前观察积累，避免历史误判污染恢复期。愈合期应设置短暂的双确认窗口：所有跨越分区边界的判定（包括恢复成员的健康认定）都需要两侧观察者同时确认，防止抖动造成的反复。

## 五、分区演练方案

分区防护不演练等于不存在。演练矩阵应包含：对称双分区——验证少数派冻结与多数派接管；不对称单向分区——验证半连通标记与回程不通的区分；三向分区——验证无多数派时的整体只读与告警；间歇分区——验证抖动下不产生频繁切换（切换频率限制器生效）；长分区愈合——验证纪元对账与冲突合并流程。每次演练的验收标准：分区中零双主（以资源层fencing拒绝计数为零为证）、少数派零写操作、多数派可用性达标、愈合后五分钟内集群状态一致。演练应在生产或准生产环境定期执行，注入手段包括iptables规则、路由撤除与专用网络故障模拟设备。

## 六、落地检查清单

- 失联结论结构化携带观察者视角，禁止无主语的死亡断言；
- 全局排他动作一律经quorum与租约，少数派自动冻结有代码级保证；
- 心跳报文含双向可达性摘要，半连通与失联是两种独立状态；
- fencing在资源层强制执行，旧纪元拒绝计数纳入监控；
- 分区期间判定冻结恢复流程有明确状态机与验收标准；
- 五类分区场景注入演练常态化，结果归档对比；
- 演练发现的每处缺陷进入修复跟踪，未闭环前不得宣布分区防护合格。
