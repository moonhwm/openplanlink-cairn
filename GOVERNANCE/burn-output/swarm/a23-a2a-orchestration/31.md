# 蜂群黑板模式原理

## 一、从指挥到共生

前三种原语(扇出聚合、规划-评审环、裁判席)都保留了中央控制流:有人派发、有人循环、有人裁决。蜂群黑板(Blackboard)反其道而行:一群各自独立的知识源(knowledge source)围绕一块共享黑板协作,谁能干什么就干什么,通过观察黑板当前状态自发决定下一步,没有总指挥。控制权从"编排器"转移到"黑板状态"本身——状态就是调度器。

这个源自上世纪语音识别研究的架构,在智能体时代重新焕发价值的原因是:大模型任务常常无法预先分解——你不知道答案藏在哪里,直到有人写下第一条线索。黑板让探索过程本身成为组织者。

## 二、三个构成要素

- **黑板(Blackboard)**:全局唯一可读写的工作区,分层存放问题求解的全部中间状态:事实、假设、部分结论、待办疑点。黑板的数据结构决定协作的上限;
- **知识源(Knowledge Source, KS)**:独立的专家模块,各自订阅自己关心的黑板层次,条件满足时被触发,读取黑板、写入增量。知识源之间不直接通信,一切交流经由黑板;
- **调度器(Monitor)**:最弱化的中央组件,只做一件事——观察黑板变化,找出当前可触发的知识源,按策略选一个执行。调度器不做业务判断,这是它与编排器的本质区别。

## 三、黑板分层:状态即议程

黑板不是一张平铺的纸,是分层的脚手架。以分析类任务为例:

```text
L0 原始输入层:  任务描述、约束、初始材料
L1 事实层:      从材料中抽取的原子事实(带来源与置信)
L2 假设层:      对事实的局部解释与工作假设
L3 结构层:      假设之间的组织:论点树、矛盾对、缺口图
L4 结论层:      达成共识的最终结论与置信评估
agenda:         由 L3 缺口与矛盾自动生成的待办事项
```

分层的意义在于触发条件可以精确表达:"当 L1 出现两条同主题但矛盾的事实时,冲突消解知识源被触发"。层次之间的依赖让自发协作仍然有序——没人能在没有事实的地基上直接盖结论。

## 四、知识源的触发契约

每个知识源声明自己的触发条件与读写范围:

```python
@dataclass
class KnowledgeSource:
    name: str
    trigger: Callable   # (blackboard) -> bool,纯谓词,无副作用
    reads: set[str]     # 订阅的层
    writes: set[str]    # 允许写入的层(越界写被黑板拒绝)
    cost: float         # 预计成本,调度排序用

    def activated_by(self, bb) -> bool:
        return self.trigger(bb.snapshot(self.reads))
```

读写范围声明是黑板的权限模型:一个知识源只能改它有资格改的层,防止分析类知识源顺手改事实层的越权行为。

## 五、调度策略:机会主义问题求解

调度器的选人策略体现"机会主义":每轮从已触发知识源中,按"黑板当前最缺什么"选最值得做的。经典优先级综合三个因子:该知识源能填补的关键缺口权重、触发条件的紧迫度(如矛盾待消解)、成本性价比。调度必须可解释——每次选择记录选择理由,否则黑板的收敛过程变成黑箱。

## 六、与三大原语的互补关系

黑板并不取代其他原语,而是承载它们:扇出聚合出现在多个知识源同时被触发、调度器并行放行的时刻;规划-评审环体现为"草拟知识源写假设层、校验知识源挑毛病、修订知识源改写"的循环;裁判席则是黑板上的特殊知识源,当结构层的矛盾无法由常规知识源消解时被触发,裁决写入结论层并回锁矛盾状态。

## 七、失效模式预警

黑板的三类固有风险:无控增殖(知识源互相触发写个不停)、震荡(两个知识源互相覆盖对方的写入)、过早收敛(某层过早被写满,后来者只能顺着既有框架走)。三者的对策分别在调度预算、写入仲裁与层级锁机制中展开,是后续子题目的主线。

## 八、黑板的引入决策

黑板模式的引入成本远高于其他三原语,决策要格外克制。引入前先过三道闸:第一道,任务确实不可预分解——用历史任务样本验证,若八成以上任务能被静态分解出合格方案,黑板的必要性存疑;第二道,团队具备状态管理基础设施——持久化、版本、并发控制有现成组件与经验;第三道,运维带宽充足——黑板出问题的排查面比消息流大一个量级,值班力量要能承接。

三道闸全过后,再选切入点:从单一任务域试点,黑板规模限制在两层(事实层加结论层),知识源不超过五个。试点期重点验证调度器的可解释性——每次选择能说清理由的黑板,才值得扩大;说不清的,先修调度再加知识源。

试点期的对照测量不能省:同批任务用"扇出加环"的旧路径并行跑,对比质量、成本、延迟。黑板只有在质量显著占优(如证据综合的完整性)或任务覆盖面显著扩大时,才有资格进入推广。势均力敌的选择永远偏向简单结构——复杂度本身是持续的成本,收益要能覆盖它。

推广节奏与试点同构:每加一类知识源、每加一层结构,都是一次小规模引入决策,重过可分解性与基础设施检查。黑板的可扩展性优势,只有在每次扩展都保持克制时才能兑现。
