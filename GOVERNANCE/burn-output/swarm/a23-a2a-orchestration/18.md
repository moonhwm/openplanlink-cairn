# 自我评审与交叉评审

## 一、两种评审的组织学

评审按"谁检查谁"分为两类:自我评审是生成者本人换一个阶段检查自己的产物;交叉评审是生成者 A 的产物交给生成者 B 检查,B 的产物交给 A 或 C。两者不是形式差异,而是纠错能力差异——它们能发现的错误类型不同,组合使用才接近完整。

自我评审能发现的是"明知故犯"类错误:格式疏漏、遗漏要求、与初稿意图的偏离。这些错误生成者是知道对错的,只是生成时没顾上。交叉评审能发现的是"认知盲区"类错误:方向性偏差、事实幻觉、隐含假设。这类错误生成者自己看不出,因为检查者与生成者共享同一套盲区时,自查等于空转。

## 二、自我评审的正确姿势

自我评审有效的前提是"换档":从生成心智切换到检查心智,具体做法有三种:

1. **换时间**:生成后冷却一段时间再检查,降低生成惯性的锚定;
2. **换视角**:检查时给自己分派一个具体身份(如"挑剔的验收员"),逐条对照清单而非通读感觉;
3. **换方向**:倒序检查、从结论往回核对证据,打破顺序阅读的自动化。

```text
自我评审清单(逐条打勾,不许跳过):
[ ] 每条要求都能指认到产物中的对应部分
[ ] 每个结论都有可回溯的依据
[ ] 格式契约逐字段核对
[ ] 声称完成而实际未完成的部分已显式标注
[ ] 与初稿相比的改动未引入新问题
```

## 三、交叉评审的配对策略

- **同侪配对**:能力相近的执行者互查,成本低,适合量大面广的常规产物;
- **异构配对**:不同特长的执行者互查(检索者查生成者、生成者查计算者),盲区互补,纠错半径最大;
- **审级配对**:更严格的模型查更宽裕的模型,适合高风险产物的终检。

配对要防"合谋":长期固定配对的评审者会互相适应对方的盲区,形成"你不说我我也不说你"的默契。定期轮换配对、抽查评审质量,是保持交叉评审锋利的例行操作。

## 四、评审意见的汇聚

交叉评审产生多份意见,汇聚规则先于分配确定:

- 严重度合并:同一缺陷被多人指出,按最高严重度计,不叠加;
- 分歧处理:对同一处一严重一轻微的分歧,标记为争议点,交裁决者(裁判席)处理,不强行平均;
- 意见去噪:与验收标准无关的风格偏好类意见单独归档,不进入修订指令。

## 五、成本档位设计

两档评审的价格不同,按产物价值分配档位:

```text
草稿级产物:  仅自我评审(清单式)
正式级产物:  自我评审 + 同侪交叉评审一轮
关键级产物:  自我评审 + 异构交叉评审 + 裁决终审
```

分档的收益是把评审预算集中在出错代价高的地方。全量最高档是最常见的浪费——多数产物在自我评审阶段就能达标,后面的档位只是仪式。

## 六、度量与校准

评审体系要有自己的度量,核心两组:检出率(评审发现的缺陷占最终确认缺陷的比例,衡量评审灵敏度)与误报率(被判为缺陷但复核否认的比例,衡量评审噪声)。自我评审与交叉评审分开统计,若交叉评审的检出率没有显著高于自我评审,说明配对策略失效,盲区未互补,该调整异构性而非增加评审轮数。评审本身也是会被模型"应付"的环节,没有度量的评审会安静地退化成走过场。

## 七、评审配对的操作细节

交叉评审的配对管理要落到具体机制:维护执行者的能力画像(擅长领域、历史检出率),配对时按互补性匹配——生成者的盲区恰好是评审者的强项。画像按月更新,检出率持续低于基线的评审者暂离池子复训,保证池内评审者的锋利度。

评审意见的传递要有标准格式,禁止自由散文:每条意见 = 位置定位 + 问题描述 + 依据条款 + 建议方向。格式不合规的意见自动退回重写。格式约束看似官僚,它保证意见可聚合、可排序、可进入修订流程,自由格式的意见最终都堆积成无人处理的评论堆。

配对的公平性要有季度审计:统计各执行者"被交叉评审的严格度"(收到的意见密度与严重度分布),确保没有谁系统性被放水或被刁难。分布异常的配对关系重新洗牌。

最后是评审负载的均衡:交叉评审是义务劳动性质,负载按产出量比例分摊,单人的评审负载设上限。超载的评审者会滑向敷衍——意见数量维持但质量崩塌,这是最隐蔽的质量损耗。负载可视化后,团队自然会把评审资源从低价值产物转向高价值产物,这比行政指令有效得多。

## 八、评审体系的演化路径

评审体系随组织成熟度演化,三段路径:起步期用清单式自评(固定检查项,逐项打勾),重点是建立"产物要被检查"的默认心智;成长期引入结构化交叉评审与标尺,重点是可比性与一致性;成熟期建设评审数据资产(检出率、误报率、缺陷分布),重点是数据驱动的评审优化。

各阶段的常见陷阱:起步期追求形式完备(标尺精美但无人校准),成长期的路径依赖(固定配对形成默契,盲区共享),成熟期的指标异化(为检出率而夸大次要缺陷)。每个陷阱的识别信号与解法都已在前文展开,这里强调的是:阶段错配是最大浪费——给起步期团队上合议制评审,或让成熟期团队还在用无锚点清单,都是资源错配。

评审体系的人力配置按产出量比例设计:评审负载与生成负载保持在一个动态平衡区间(经验起点是评审占团队工时的两成),失衡时优先调整产物分档(缩小高成本评审的适用面),而非压榨评审者。可持续的评审体系,负载必须是可持续的。

最后,把评审体系的运行数据纳入组织年报:全年检出的缺陷数、避免的返工成本估算、评审者的成长轨迹(个人检出率的进步)。评审常被视为成本中心,年报让它以质量发动机的身份被看见——被看见的投入,才能持续获得投入。
