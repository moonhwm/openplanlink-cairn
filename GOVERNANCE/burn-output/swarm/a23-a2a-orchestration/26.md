# 裁判偏置与校准

## 一、偏置清单

模型裁判的系统性偏置是可枚举、可检测、可部分校正的。主要类型:

1. **位置偏置**:并列选项中偏好特定位置(常见于首位或末位);
2. **冗长偏置**:偏好更长、更详细的回答,把篇幅当质量;
3. **自偏好**:偏好同家族模型生成的风格;
4. **顺序敏感**:成对比较中"后看到的"印象更深;
5. **标准漂移**:长会话或多案连裁时,前面的案例拉高或拉低后面的尺度;
6. **自信偏置**:对表述果断的选项给分更高,把语气当证据强度。

每一类偏置都有对应的检测协议,不能凭感觉断言"我们没这个问题"。

## 二、检测协议

```text
位置偏置:   同一对选项交换顺序重裁 N 次,统计结论翻转率
冗长偏置:   等价内容做长短两版,统计分数差与长度差的相关
自偏好:     标注集按生成者分组,比较组间分数分布
标准漂移:   同一案例在不同裁次位置重放,分数差即漂移量
自信偏置:   等价内容做克制/果断两版语气,比较得分
```

翻转率、相关系数、组间分布差都要落到季度报告里,偏置检测是裁判体系的一级运维,不是一次性上线检查。

## 三、校正手段分层

检测出偏置后,校正按侵入性分四层:

- **提示层**:裁判提示中加入明确的反偏置指令与程序约束(先逐维度打分、禁止以长度论优劣),成本最低,效果有限;
- **过程层**:随机化呈现顺序、成对比较双向裁决、风格归一化预处理,在输入端物理消除偏置诱因,效果最实;
- **统计层**:对已知方向的偏置做事后修正(如长度回归的残差校正),适合历史数据重估;
- **架构层**:换用异构裁判、引入合议稀释单一偏置,成本最高,留给顽固偏置。

## 四、校准的操作闭环

校准不是一次动作,是持续闭环:

1. 维护人工标注的金标集,覆盖各维度各难度;
2. 裁判定期对金标集盲测,输出与金标的一致率、按维度的偏差方向;
3. 偏差超阈触发校正动作(改提示、调程序、换模型);
4. 校正后金标集重测,确认回正;
5. 全过程留档:每次校准的裁判版本、提示版本、成绩单。

## 五、裁判间的公平性

多裁判体系还有裁判间的公平问题:不同裁判的宽严尺度不一,跨裁判的分数不可直接比较。处理方式:定期交叉裁同一批锚点,估计各裁判的宽严系数,跨裁判统计时做校正;或干脆按裁判分桶统计,不做跨桶比较。校准的元目标是让"分数"成为体系通用货币,任何未校准的新裁判上线,都相当于往货币体系里掺假币。

## 六、被校准反向利用的风险

要警惕生成端"研究裁判":生成者(或其背后的优化过程)发现裁判偏好长文、偏好果断语气,就会朝偏置方向优化产物,质量不变而分数虚高。防御:校准报告与偏置清单对生成端保密是无效的(会被观察到),有效的是周期性换裁判组合、掺入人工抽检、监控"分数上涨而人工复核质量不涨"的剪刀差——剪刀差扩大就是被反向利用的铁证,此时必须先修裁判再谈质量。

## 七、偏置治理的季度流程

偏置治理固化为例行季度流程:第一周跑检测协议全套(位置、冗长、自偏好、顺序、漂移、自信六组实验),产出偏置强度报告;第二周按报告制定校正计划,提示层、过程层、统计层各领任务;第三周实施校正并重跑实验验证;第四周把残留偏置写入已知问题清单,连同校正记录归档。

检测协议的实验设计要防"被应试":实验样本与日常裁决样本分开构造,相同实验不重复使用同一批材料(重复使用的对照材料会被优化过程记忆)。实验本身也要抽样人工验证——对照材料若本身不等价(两版内容真有质量差),实验结论方向性错误。

校正效果的评估周期要拉长:过程层校正(随机化、归一化)立即生效可当周验证;统计层校正(残差修正)需要积累新样本,按月评估;提示层校正的效果最不稳,衰减快,纳入每月轻检。三层校正的维护成本递减,优先投入过程层是性价比最高的选择。

最后把偏置指标纳入裁判体系的公开仪表盘:校准一致率、各偏置强度、已知问题清单对全部干系人可见。透明是偏置治理的放大器——看不见的偏置治理依赖个别人的自觉,看得见的偏置治理会成为整个质量体系的标准动作。

## 八、偏置研究的进阶方法

当基础检测协议全部跑顺后,偏置研究可以进阶到交互效应:单一偏置的检测之外,研究偏置的组合放大——长度偏置与自信偏置叠加时,果断的长答案对简短的谨慎答案的胜率是否远超两者单独效应之和。交互效应的检测用因子化实验设计(两因素两水平全组合),样本量按效应量预估。

进阶研究的另一个方向是任务条件化偏置:同一偏置在不同任务类型上的强度差异(事实核查类任务对冗长偏置的免疫力高于观点评析类)。条件化的成果写入边界文档(见模型裁判一章),路由时把易感任务类型配给偏置豁免的裁判或加强过程层校正。

偏置研究的方法论本身要存档:每个检测协议的实验设计、样本构造、统计方法、复现步骤,写成可重复的实验手册。方法论存档保证检测协议在人员更替后仍能忠实执行——偏置检测最怕的就是协议悄悄变形,三代之后测的已不是原来的偏置。

研究产出的最终形态是"偏置地图":以裁判为行、偏置类型为列的强度矩阵,随季度检测更新。地图挂在质量看板的显眼处,任何派发决策都能一眼看到目标裁判的偏置轮廓。可视化不是装饰——被看见的偏置才会被防御,看不见的偏置永远在暗处收税。
