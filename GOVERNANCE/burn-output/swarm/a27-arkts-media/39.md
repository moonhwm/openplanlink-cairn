# 39 · 混音播放策略：SHARE 模式与多流共存实践

> 一句话摘要：混音策略的目标是"多个声音合理共存"：主内容走 INDEPENDENT 保独占体验，伴生/提示流走 SHARE 与静音混音开关，音频用途（usage）的正确标注决定混音在音量曲线与焦点表中的归宿。

## 一、多流共存的三个产品形态

形态一：应用内双流——背景音乐 + 实时音效（游戏、K 歌），两条流属于同一应用，共存是常态，音量平衡由实例音量控制（第 6/21 篇）。形态二：跨应用伴生——用户开着音乐应用，同时使用带按键音/提示音的本应用，产品上"不必打断音乐"是体验加分项。形态三：必达提示——导航、跑步提醒这类"必须被听见"的短播报，既需要压低音乐又不能完全杀死对方。三种形态对应三种技术组合：形态一用实例音量自平衡；形态二把伴生流设 SHARE_MODE（不参与对等抢占）；形态三保持 INDEPENDENT 但配合高优先 usage，让系统仲裁产生 DUCK 而非 PAUSE。

## 二、多流配置实现

```typescript
import { audio } from '@kit.AudioKit';

export class MixBus {
  // 流1：伴生短提示（SHARE，静音模式下也出声——如版本提供该开关）
  async makeAlertSfx(): Promise<audio.AudioRenderer> {
    const r = await audio.createAudioRenderer({
      streamInfo: {
        samplingRate: audio.AudioSamplingRate.SAMPLE_RATE_48000,
        channels: audio.AudioChannel.CHANNEL_1,
        sampleFormat: audio.AudioSampleFormat.SAMPLE_FORMAT_S16LE,
        encodingType: audio.AudioEncodingType.ENCODING_TYPE_PCM
      },
      rendererInfo: { usage: audio.StreamUsage.STREAM_USAGE_GAME, rendererFlags: 0 }
    });
    r.setAudioInterruptMode(audio.InterruptMode.SHARE_MODE);   // 不抢别人的音乐
    // 若版本支持：系统静音开关下仍出声（导航/提醒类语义），按需开启
    // r.setSilentModeAndMixWithOthers(true);
    return r;
  }

  // 流2：主内容（INDEPENDENT，正常参与焦点竞争）
  applyMainPolicy(p: media.AVPlayer) {
    p.audioInterruptMode = audio.InterruptMode.INDEPENDENT_MODE;
  }
}
```

## 三、共存纪律与验证

纪律一，usage 决定归宿。SHARE 只解决"抢不抢"，混音后的音量曲线归属、在焦点表中的优先级位置由 usage 决定：提示类不要错标 VOICE_COMMUNICATION（会被拉进通话路由与回声消除链路），内容类错标 RING 类更不允许。纪律二，混音不等于大声。伴生流的实例音量应低于主内容（0.4~0.7 区间起步），并尊重应用内"音效开关"偏好；必达提示才用满音量。纪律三，静音开关语义。系统静音/勿扰下媒体流默认消音，导航与提醒类若必须出声，用静音混音类开关显式声明并做好用户告知，不得静默绕过用户意图。纪律四，验证矩阵：本应用提示流(SHARE) + 他应用音乐(INDEPENDENT)——双声叠加，音乐不中断；本应用 SHARE 流自身不被他应用音乐抢断；来电场景全通道让位（SHARE 也躲不开最高优先级）。真机上再叠加有线/蓝牙两种输出验证混音通道一致性。

## 四、混音策略检查清单

- [ ] 应用内每条流标注"内容/伴生/必达"三类之一，模式与 usage 按类设置。
- [ ] 伴生流实例音量低于主内容，尊重用户音效开关。
- [ ] 静音混音开关仅用于必达提示，且产品文案向用户说明。
- [ ] 跨应用互测：SHARE 与 INDEPENDENT 的共存、来电全让位两类场景。
- [ ] 混音音质检查：双流叠加无削波失真（总增益留余量）。
- [ ] 策略与第 37 篇决策表合并维护，新增流先过表再写码。

混音是"共存的策略"，下一篇的 Ducking 则是"让路的礼仪"：被压低时如何优雅地把路让出来再收回来。
