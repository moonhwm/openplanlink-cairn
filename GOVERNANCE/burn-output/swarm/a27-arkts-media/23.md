# 23 · AudioRenderer 正弦波生成与实时合成示例

> 一句话摘要：用 AudioRenderer 现场合成正弦波是验证 PCM 链路的最小完备实验，它把采样定理、幅度量化、交错声道、相位连续性四个知识点压缩进几十行代码，也是游戏合成器与提示音引擎的原型。

## 一、从频率到样本：合成的数学骨架

数字音频里"一个 440Hz 的音"意味着：每秒采样 48000 次中的第 n 个样本取值 `A·sin(2π·440·n/48000)`。其中 A 是幅度（S16LE 下最大 32767，留余量常取 0.3×32767 防削波失真）；`n/48000` 是该样本的时间戳；2π·f·t 是瞬时相位。四个工程要点：其一，**相位连续性**——分块合成时相位必须跨块累计（维护 `phase` 变量按步进 `2πf/fs` 递增并周期性取模），每块从零起相位会发出周期性"咔哒"声，这是合成音频第一大坑；其二，**幅度渐进**——起止各做 5~10ms 的线性淡入淡出，硬起止同样产生爆音；其三，**声道交错**——双声道帧按 [左,右,左,...] 交错存储，Int16Array 偶数位左、奇数位右；其四，**量化取整**——浮点幅度乘满量程后取整写入 Int16Array，避免直接截断到字节层造成噪声。

## 二、完整可运行示例

```typescript
import { audio } from '@kit.AudioKit';

export class TonePlayer {
  private renderer!: audio.AudioRenderer;
  private phase = 0;                       // 跨块相位累计（弧度）
  private readonly fs = 48000;
  private freq = 440;

  async start() {
    this.renderer = await audio.createAudioRenderer({
      streamInfo: {
        samplingRate: audio.AudioSamplingRate.SAMPLE_RATE_48000,
        channels: audio.AudioChannel.CHANNEL_2,
        sampleFormat: audio.AudioSampleFormat.SAMPLE_FORMAT_S16LE,
        encodingType: audio.AudioEncodingType.ENCODING_TYPE_PCM
      },
      rendererInfo: { usage: audio.StreamUsage.STREAM_USAGE_GAME, rendererFlags: 0 }
    });
    await this.renderer.start();
    this.renderer.on('writeData', (buf: ArrayBuffer) => this.fill(buf));
  }

  private fill(buf: ArrayBuffer) {
    const out = new Int16Array(buf);
    const step = 2 * Math.PI * this.freq / this.fs;      // 每样本相位步进
    const amp = 0.3 * 32767;                             // 留 headroom 防削波
    const frames = out.length / 2;                       // 双声道：帧数=样本对数
    for (let i = 0; i < frames; i++) {
      const s = Math.round(amp * Math.sin(this.phase));
      out[i * 2] = s;                                    // 左
      out[i * 2 + 1] = s;                                // 右（同相信号）
      this.phase = (this.phase + step) % (2 * Math.PI);  // 相位累计并归一
    }
  }

  setFreq(hz: number) { this.freq = hz; }                // 变频无咔哒：相位不断
  async stop() {
    this.renderer.off('writeData');
    await this.renderer.release();
  }
}
```

## 三、从正弦到实用合成的扩展路径

单音验证链路后，工程化扩展沿四个方向：一是**多音叠加与包络**——把若干 `A_i·sin(2πf_i·t+φ_i)` 相加并用 ADSR（起音-衰减-延音-释音）包络乘幅度，即得复音合成器，注意多音求和后总幅度可能超满量程，需要软限幅（tanh 压缩）或归一化；二是**提示音编排**——按键音、到账提示等短音效用"频率-时长-包络"参数表驱动 fill 函数，一段生成逻辑覆盖全部产品音效，省去打包大量音频文件；三是**数据源切换**——把 fill 中的合成换成从解码器/网络队列取数，回调基建完全不变（第 19 篇）；四是**可视化并行**——合成的同时把样本幅值推给频谱组件，注意降采样到 UI 刷新率（30~60fps）再投递，避免每回调都触发重绘。

## 四、合成链路检查清单

- [ ] 相位跨块累计并取模，杜绝块边界爆音。
- [ ] 幅度留 headroom（≤0.5 满量程），多音叠加做软限幅。
- [ ] 起止与变参数处加 5~10ms 淡变，频率切换保持相位连续。
- [ ] 双声道按帧交错写入；块大小、帧数、字节数换算复核。
- [ ] 变频/变幅接口线程安全（回调线程与 UI 线程竞争）。
- [ ] 长时间运行监听欠载（静音兜底计数应为零）。

这个百行内的原型同时是第 17、18、19 篇知识的联练习场：参数契约、状态推进、回调供数任何一环出错，正弦波都会诚实地以噪声、咔哒或无声反馈给你。
