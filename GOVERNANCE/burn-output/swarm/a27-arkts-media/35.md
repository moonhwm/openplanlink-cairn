# 35 · 后台保活边界：省电约束、任务重启与冷启动恢复

> 一句话摘要：音频长时任务是唯一的合法保活通道，其边界由"名实相符"划定；进程被杀后的冷启动恢复（控制中心点播唤起）靠持久化播放态 + WantAgent 路由 + 会话重建三件套达成。

## 一、保活的合法边界

系统对后台的限制层层加码：普通应用退后台数秒后冻结（挂起），长时任务是用户可感知场景的豁免通道。对 AUDIO_PLAYBACK 而言，"名实相符"就是任务存续期内始终有声：暂停超过窗口不撤任务、用音频任务撑着做下载/上报等无关工作、循环播放无内容静音，都属于滥用形态，系统会终止任务；被终止的应用在一段时间内更难再次申请，部分版本还会在电池设置里向用户展示后台耗电记录。正确的资源观是：保活不是目的，"用户预期的声音不断"才是目的——暂停即撤任务、恢复再申请（第 28 篇滞回窗口），下载等长耗时工作改用对应的任务类型（如上传下载型长时任务）而不是蹭音频通道。省电约束方面：任务存续期内应主动收缩非必要活动——停止 UI 渲染相关刷新、降低日志、暂停分析与埋点批量上报中的高频项，把后台电量集中在音频链路上。

## 二、冷启动恢复三件套

```typescript
// 件一：播放态持久化（每次状态变化与心跳时落盘）
export class PlayStateStore {
  save(s: { assetId: string; positionMs: number; playing: boolean }) {
    preferences.putSync('last_play', JSON.stringify(s));
    preferences.flush();                          // 及时落盘，进程随时可能被杀
  }
}

// 件二：冷启动路由（EntryAbility onCreate解析want）
onCreate(want: Want) {
  const fromMedia = want?.parameters?.['entry'] === 'from_media_task';
  const wantPlay = want?.parameters?.['cmd'] === 'play';   // 控制中心点播
  AppStorage.setOrCreate('route', fromMedia ? 'PlayerPage' : 'Home');
  AppStorage.setOrCreate('autoResume', wantPlay);
}

// 件三：会话重建与断点续播（PlayerPage aboutToAppear）
async aboutToAppear() {
  const last = JSON.parse(preferences.getSync('last_play', '{}'));
  if (last.assetId && AppStorage.get('autoResume')) {
    const item = await mediaLibrary.findById(last.assetId);
    await this.svc.open(item);                    // 建AVPlayer+AVSession+长时任务
    await this.svc.seekTo(last.positionMs);
    await this.svc.play();
  }
}
```

## 三、重启路径上的细节

第一，控制中心点播的命令到达形态：进程已死时表现为"带参数的 ability 启动"（want parameters 携带命令标记），进程活着时表现为 session 命令回调——两条路径都要通，路由层统一翻译成 svc.play()。第二，续播的进度来源是本地持久化快照而非任何内存态；心跳保存节律（如 5 秒）与 position 快照同帧，杀进程最多丢一个心跳周期的进度。第三，恢复失败的兜底：assetId 对应内容已被删除（下架/清理）时，降级为打开播放页并提示内容不可用，绝不能卡在无声的"播放中"状态（同时不要申请长时任务）。第四，重进应用与冷启动恢复的区分：用户主动打开应用到首页是常规路由，只有来自媒体框架的启动（entry 标记）才自动跳播放页，避免"每次打开都被甩到播放页"的骚扰。

## 四、保活与恢复检查清单

- [ ] 暂停滞回超时撤任务；任务期内无静音空转；不做任务外挂工作。
- [ ] 播放态持久化与心跳同帧，flush 及时。
- [ ] 冷启动：控制中心点播→拉起→路由播放页→续播，全链路真机验证。
- [ ] 内容失效降级路径明确，无"无声播放中"僵尸态。
- [ ] entry 标记区分媒体框架启动与用户主动启动，路由策略分离。
- [ ] 后台耗电曲线达标：任务期电量集中在音频，UI/埋点等非必要活动收缩。

保活与恢复是后台播放的"韧性层"，下一篇处理物理世界的问题：耳机拔出与蓝牙切换。
