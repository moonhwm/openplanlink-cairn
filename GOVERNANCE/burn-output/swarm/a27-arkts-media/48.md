# 48 · 播放功能测试清单与调试技巧（日志/Profiler/常见问题）

> 一句话摘要：播放功能的可测性来自"状态机用例表 + 双端互测矩阵 + 真机场景库"三层用例与"hilog 定点日志、HiTrace 链路、Profiler 资源曲线"三件工具，配合高频缺陷速查表把排障从经验变成流程。

## 一、三层用例体系

第一层是内核状态机用例：以第 1 篇状态图为用例源，覆盖合法迁移（idle→initialized→prepared→playing→paused→completed→stopped→released）与代表性非法调用（idle 态 play、error 态 seek）断言错误而不断言崩溃；第 38 篇的打断矩阵逐格生成注入用例（FakeKernel 模拟事件序列，第 45 篇的可注入架构）。第二层是双端互测矩阵：本应用 × 对手应用（另一音乐应用、来电、导航、语音助手）× 设备形态（扬声器/有线/蓝牙）的组合，验证焦点、混音、ducking 的真实仲裁行为——这类只能真机执行，按季度与系统版本更新基线。第三层是场景库：锁屏控制、控制中心切会话、冷启动恢复、耳机拔插、蓝牙断连、弱网缓冲、息屏后台 30 分钟、切歌压测 100 次、内存低端机专项，每个场景有明确的通过判据（判据写进用例，不靠测试者手感）。

## 二、调试工具与定点日志

```typescript
// 定点日志锚点：覆盖命令、状态、事件、资源四类关键断面
export const TAG = 'MediaApp.Player';
export const anchors = {
  cmd:   (name: string) => hilog.info(0x0, TAG, `[CMD] ${name} @${Date.now() % 1e6}`),
  state: (from: string, to: string) => hilog.info(0x0, TAG, `[STATE] ${from}->${to}`),
  evt:   (name: string, arg: string) => hilog.info(0x0, TAG, `[EVT] ${name} ${arg}`),
  res:   (action: string) => hilog.info(0x0, TAG, `[RES] ${action}`),   // open/close fd、create/release
};
// 排障时按 [CMD]->[STATE]->[EVT]->[RES] 时序还原现场；
// 跨组件调用链配 HiTrace 打点，把锁屏命令到内核动作串成一条trace。
```

工具用法：hilog 过滤 `MediaApp.Player` 标签即可回放一次播放会话的完整决策链；HiTrace 用于"命令丢失"类问题的链路定位（锁屏点击后哪一环没走）；DevEco Profiler 的 Memory 面板看实例与封面曲线（第 47 篇脚本），CPU 面板看后台心跳与回调开销；设备侧开发者选项的音频路由/焦点提示（随版本提供）辅助双端互测观测。远程问题依赖第 46 篇的错误上报聚合，本地日志只留锚点级、避免刷屏。

## 三、高频缺陷速查表

| 症状 | 首查 | 次查 |
|---|---|---|
| 黑屏有声 | surfaceId 绑定晚于 prepare（第7篇） | onLoad 时机、实例复用悬空 |
| 后台几分钟后停 | 长时任务名实不符/未申请（第28篇） | 省电模式、任务被系统终止记录 |
| 锁屏进度不动 | position 快照 updateTime 错（第32篇） | state 卡在 BUFFERING 未恢复 |
| 切歌内存上涨 | fd 未关、预加载池泄漏（第12/13篇） | 封面 PixelMap 未释放 |
| 打断后不恢复 | 被动/主动标志被用户操作清除（第10篇） | SHARE 分支未自行执行 |
| 耳机拔出外放 | 拔出暂停策略缺失（第36篇） | 双通道事件去重失效 |
| 幽灵播控卡片 | 会话未 destroy（第30篇） | 多会话并存，最后创建者错位 |
| 第二次进页无声 | 上次实例未 release（第18/22篇） | 音频流名额耗尽 |

## 四、测试与调试检查清单

- [ ] 三层用例入库并有自动化部分（状态机/打断矩阵可注入离线跑）。
- [ ] 定点日志四锚点（CMD/STATE/EVT/RES）覆盖核心链路，release 版可关。
- [ ] 真机场景库按判据执行，季度与系统版本更新基线。
- [ ] 速查表随缺陷库持续维护，新缺陷先入表再修。
- [ ] Profiler 脚本（切歌/滚动/后台）纳入发布前例行。
- [ ] 遥测聚合错误族分布，异常上涨触发回归。
