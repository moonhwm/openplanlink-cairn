# 31 · AVSession 元数据设置：标题、作者、时长与封面

> 一句话摘要：`setAVMetadata` 把当前播放项的展示信息登记到系统播控，assetId 是换曲识别键、duration 单位为毫秒、封面经 PixelMap 传入且必须及时释放，元数据与真实内容错位是锁屏展示类缺陷的主要来源。

## 一、字段语义与设置时机

`AVMetadata` 的核心字段：`assetId`（必填，媒体项唯一标识，系统以它判断"是不是换了内容"，建议用内容 ID 而非数组下标）；`title`/`artist`/`album`（标题/艺术家/专辑，来自媒体库或 AVMetadataExtractor，第 15 篇）；`duration`（毫秒，注意与 AVPlayer `duration` 属性单位一致，都是毫秒）；`subtitle`/`description`（副标题与描述，播客常用 subtitle 放节目名）；`lyric`（歌词 uri，部分版本支持）；`mediaImage`/封面字段（PixelMap 形式）。设置时机有两处：activate 之前的"首版元数据"（保证卡片一出现就有内容），以及每次切歌后的"更新版"。切歌时先 play 新曲、再 setAVMetadata，最后更新 playbackState——让封面标题与声音同帧切换，避免"新歌声音、旧歌封面"的错位窗口。

## 二、设置模板与封面处理

```typescript
import { avSession } from '@kit.AVSessionKit';
import { image } from '@kit.ImageKit';

export async function pushMetadata(s: avSession.AVSession, item: MediaItem,
                                   coverUri?: string) {
  const meta: avSession.AVMetadata = {
    assetId: item.id,                       // 内容唯一键：换曲识别
    title: item.title,
    artist: item.artist ?? '未知艺术家',
    album: item.album,
    duration: item.durationMs               // 毫秒
  };

  if (coverUri) {
    // 封面：解码为合适尺寸的PixelMap再传入（控制在256~512px级）
    const src = image.createImageSource(coverUri);
    const pm = await src.createPixelMap({
      desiredSize: { width: 360, height: 360 }
    });
    meta.mediaImage = pm;                   // 传给系统后按需release（见清单）
  }

  try {
    await s.setAVMetadata(meta);
  } finally {
    // PixelMap所有权策略以文档为准；不确定时保留引用由缓存统一回收
  }
}
```

## 三、工程细节与坑位

第一，封面内存治理。媒体封面是播控类应用内存大户：解码成 PixelMap 时用 `desiredSize` 限制到展示尺寸（锁屏卡片无需原图 2000px），并用 LRU 缓存管理（键 assetId），滚动列表预解码上限设 8~12 张；传给系统后注意 PixelMap 的持有与释放策略，防止"设一次封面涨一截内存"。第二，assetId 的稳定性。用内容 ID 保证跨次启动稳定：系统控制中心据此识别"上次在播的内容"，冷启动恢复（第 35 篇）也依赖它回查本地记录；数组下标做 assetId 在列表重排后会错乱。第三，特殊字符与超长文本。标题里的换行、控制字符要清洗，超长标题截断由系统展示层处理，但源数据里堆积垃圾字符会造成卡片排版异常。第四，本地文件封面。内嵌封面先由 AVMetadataExtractor 抽出（第 15 篇），落缓存目录后按 URI 解码；无封面时使用应用统一占位图，不要放任空白卡片。第五，播客/听书类建议补全 subtitle 与 duration，控制中心的进度条信赖 duration，缺失会导致进度条不显示或比例失真。

## 四、元数据检查清单

- [ ] assetId 用稳定内容 ID；activate 前设首版，切歌后即时更新。
- [ ] duration 毫秒单位与 AVPlayer 一致；异常时长兜底为 0 并隐藏进度条。
- [ ] 封面解码限定尺寸 + LRU 缓存，内存曲线纳入监控。
- [ ] 标题/艺术家空值兜底文案；特殊字符清洗。
- [ ] 无封面统一占位图；本地内嵌封面走元数据抽取缓存。
- [ ] 换曲时序固定：切音源→元数据→状态，真机验证无错位窗口。

元数据解决"系统播控上显示什么"，下一篇的 playbackState 解决"显示播到哪、什么状态"。
