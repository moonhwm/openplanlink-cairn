# 33 · AVSession 控制命令监听：play/pause/next/previous/seek/stop

> 一句话摘要：AVSession 通过 `on('play')`、`on('seek')` 等一族命令监听接收系统播控下发的控制意图，命令处理函数必须与 UI 按钮共用同一条业务链路并即时回写状态，形成"命令—执行—镜像"的闭环。

## 一、命令族全景

AVSession 的控制命令按能力位注册：基础传输命令 `play`/`pause`/`stop`/`playNext`/`playPrevious`/`seek`（毫秒参数），偏好类命令 `toggleFavorite`、`setLoopMode`，以及 `playPause` 合并命令等（命令集合与名称以所用版本 AVSessionKit 文档为准）。未注册监听的命令不会出现在锁屏控件上（或呈现为不可用），因此"产品想露出什么按钮"直接由注册面决定：纯音乐应用注册六个基础命令；听书应用常隐藏 previous 或映射为"回退 30 秒"；不支持收藏的应用不注册 toggleFavorite。除监听外，还需通过 `setAVCommands`/能力声明（按版本 API）告知系统支持的命令集合，两处保持一致。

## 二、命令路由器实现

```typescript
import { avSession } from '@kit.AVSessionKit';

export function bindCommands(s: avSession.AVSession, svc: PlayerService) {
  // 与UI按钮完全共用svc的方法：单一事实源（第26篇）
  s.on('play',  () => svc.play());
  s.on('pause', () => svc.pause());
  s.on('stop',  () => svc.stop());
  s.on('playNext',     () => svc.next());
  s.on('playPrevious', () => svc.prev());
  s.on('seek',  (time: number) => svc.seekTo(time));          // 毫秒
  s.on('toggleFavorite', (assetId: string) => svc.toggleFav(assetId));
  s.on('setLoopMode', (mode: avSession.LoopMode) => svc.setLoop(mode));

  svc.on('favoriteChanged', (id, fav) => {
    s.setAVPlaybackState({ /* isFavorite: fav, state维持 */ } as avSession.AVPlaybackState);
  });
}

export function unbindCommands(s: avSession.AVSession) {
  ['play','pause','stop','playNext','playPrevious','seek',
   'toggleFavorite','setLoopMode'].forEach(e => { try { s.off(e); } catch {} });
}
```

## 三、命令处理的四条纪律

纪律一，命令与 UI 同链路。锁屏"下一首"与界面"下一首"必须调用同一个 `svc.next()`，任何一侧绕过服务直改播放器都会造成状态分叉（第 26 篇的单一事实源原则在命令层的落地）。纪律二，执行后必须镜像。命令处理完要触发第 32 篇的状态同步——尤其是"seek 后锁屏进度条立即落位"依赖 seekDone + 快照推送；只执行不镜像，系统控件与真实状态脱节，用户会反复点击。纪律三，幂等与防抖。锁屏快速连点"下一首"（每次切歌有prepare耗时）要做命令队列化或执行中标志，把在途命令合并为最后一个，避免实例池被打穿。纪律四，快命令慢处理。命令回调本身要快速返回，把 prepare/seek 等慢操作放入异步任务；某些系统实现会等待回调返回再更新控件状态，长时间阻塞回调会拖住整个播控面板。

## 四、命令链路检查清单

- [ ] 注册面与产品控件面一致；不支持的命令不注册。
- [ ] 全部命令路由到统一 PlayerService，与 UI 无旁路。
- [ ] 每条命令执行后触发状态镜像（含 favorite/loopMode 偏好回写）。
- [ ] 连点场景命令合并；seek 命令与本地拖拽共用去抖（第4篇）。
- [ ] 回调内只做投递，慢操作异步化，不阻塞播控面板。
- [ ] destroy 前 off 全部命令监听（配合第30篇销毁序列）。

命令链路接通后，应用就完整融入了系统媒体生态，下一篇从用户视角走查三端（锁屏/通知/控制中心）的联动体验。
