# 43 · 系统音量管理：AudioVolumeManager 与音量监听

> 一句话摘要：系统音量按流类型（VolumeType）管理，应用通过 `AudioVolumeManager` 查询/设置与监听音量变化，"跟随系统音量做 UI 镜像、绝不用实例音量冒充系统音量"是音量交互的铁律。

## 一、流音量模型

系统把音量组织为若干条独立曲线：媒体（STREAM_MUSIC，音乐/视频/游戏）、通话、铃声、提示音等，各自有自己的当前档位与步进范围（媒体典型 0~15 级，具体以设备为准）。用户按音量键改的是"当前焦点流的曲线"——音乐播放中按键改媒体音量，这解释了为什么音乐应用的音量滑条必须绑定媒体流曲线而不是任何实例参数。应用侧入口：`audio.getAudioManager().getVolumeManager()` 得到 `AudioVolumeManager`，其 `getVolumeSync(volumeType)` 查询当前档位、`getMaxVolumeSync(volumeType)` 查询上限、`setVolume(volumeType, level, flag)` 设置档位（多数版本需要系统应用权限，三方应用通常只能跟随不能改，以实际权限模型为准）、`on('volumeChange', cb)` 监听变化（回调携带流类型、新档位、是否由用户触发等信息）。设置接口的三方可用性受限是常态设计，应用的正确定位是"镜像 + 提示"，把修改权留给用户与系统。

## 二、音量镜像组件

```typescript
import { audio } from '@kit.AudioKit';

export class VolumeMirror {
  private vm = audio.getAudioManager().getVolumeManager();
  private type = audio.VolumeType.STREAM_MUSIC;

  current(): { level: number; max: number; ratio: number } {
    const level = this.vm.getVolumeSync(this.type);
    const max = this.vm.getMaxVolumeSync(this.type);
    return { level, max, ratio: level / max };
  }

  watch(cb: (ratio: number, muted: boolean) => void): void {
    this.vm.on('volumeChange', (vol: audio.VolumeEvent) => {
      if (vol.volumeType !== this.type) return;          // 只镜像媒体曲线
      cb(vol.volume / this.vm.getMaxVolumeSync(this.type),
         vol.volume === 0);
    });
  }

  unwatch(): void { this.vm.off('volumeChange'); }
}
```

## 三、交互设计要点

要点一：滑条语义。应用内音量滑条展示 `getVolumeSync/max` 比例，拖动时若权限允许则 setVolume，否则仅展示并引导物理键/控制中心——绝不能把实例音量（setVolume(0~1)）当系统音量给用户拖：那会出现"滑条拉满但整体很轻"（用户系统音量本来低）或"滑条无效"（实例音量改动不影响其他流）的双向误解。要点二：静音与零档位。媒体曲线的 0 档即静音，UI 上等价呈现"已静音"图标；实例静音与系统静音是两层，产品文案不要混称。要点三：监听节流。用户长按音量键会产生密集 volumeChange，UI 刷新合并到 100ms 粒度；勿在回调里做重活。要点四：与打断联动。DUCK 压低是实例级动作（第 40 篇），不改变系统流音量，锁屏音量条不应因 duck 跳动——若发现联动异常先检查是不是把两层音量混用了。要点五：多端一致。音量镜像的状态在页面重建时重拉（onPageShow/aboutToAppear），不要依赖上一页面的陈旧值。

## 四、音量管理检查清单

- [ ] 音量 UI 绑定媒体流曲线（getVolumeSync/max），实时镜像 volumeChange。
- [ ] 实例音量只用于应用内多流平衡，不冒充系统音量。
- [ ] setVolume 的权限适用性确认，无权限则走展示+引导。
- [ ] 静音态图标区分系统零档与实例静音，文案不混称。
- [ ] 监听回调节流 100ms，页面销毁 off。
- [ ] duck/unduck 期间确认锁屏音量条不随之跳动（两层解耦验证）。
